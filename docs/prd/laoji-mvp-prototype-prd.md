- 版本：Prototype PRD v1.6
- 状态：UI 设计与开发的产品输入
- 日期：2026-08-03；2026-08-09 完成 MVP 收敛、交互与设计自由度一致性审查
- 适用端：响应式 Web，覆盖桌面、平板和手机
- 目标读者：UI 设计师、产品、前端、后端、测试和后续 agent

### 0.1 2026-08-07 至 2026-08-09 原型对齐总表

本节记录 2026-08-03 至 2026-08-09 已落地并确认的产品与交互调整。它覆盖本文档中较早的页面草图和局部旧描述；未列出的产品边界继续遵循正文。本文只约束能力、内容、流程、状态、文案和验收结果；导航承载、区块位置、分栏方式、抽屉/面板方向及具体响应式布局由 Open Design 决定。全文 ASCII 示意只用于核对信息与流程，不是布局要求。

**全局 Shell、对话与个人资料**

- 已登录页面统一提供“对话 / 读书 / 设置”三个一级入口，并在各端提供可发现的个人设置入口；具体导航形态和位置由 Open Design 决定。
- 系统提供国风默认头像。用户可在设置中选择 JPG、PNG 或 WebP 图片，限制 2MB；头像与昵称保存后跨页面同步，恢复默认头像不删除其他资料。
- 设置首页统一分为“个人资料 / 已连接的服务 / 存储、安全与退出”。AI 与微信读书仍使用独立配置页，设置首页只展示状态和管理入口。
- 对话支持应用内多会话，各端都能新建、切换和管理会话；具体会话入口及承载方式由 Open Design 决定。新对话默认不继承书籍上下文。
- 从书籍发起制作 PPT 时，自动创建绑定该书的 PPT 专属会话；用户在普通对话中提出制作 PPT 时，也触发同一流程，并在书籍明确后将当前会话绑定为 PPT 会话。删除会话只删除聊天记录，PPT 草稿和作品仍从书籍的“读书 PPT”找回。

**认证与账户恢复**

- 登录、注册和密码恢复使用独立认证布局，不显示已登录产品导航。
- 密码字段提供明确的显示/隐藏图标按钮；字段错误就地显示并保留合法输入，提交期间禁止重复提交。
- 密码恢复区分申请邮件、邮件已发送、链接失效、设置新密码和成功五个视图；成功后返回登录，不自动假设用户已登录。

**对话首页**

- 对话是登录后的默认入口，并提供最近阅读、最近笔记、最近作品和当前书籍上下文的可发现入口；各端如何组织和展开这些内容由 Open Design 决定。
- 首次空状态提供“打开书架”和“导入书籍”两个真实入口，不显示配置卡。
- AI 未配置时保留当前输入，显示就地拦截；用户可以去配置或取消并继续编辑。配置成功后返回原页面和对话上下文。
- 用户通过书籍入口或在对话中表达“帮我制作 PPT”等明确意图，都进入绑定单本书的 PPT 流程；书籍不明确时先在当前对话选择，再由对话引导范围与需求。

**统一书架**

- 书籍卡片整体点击进入对应的书籍工作区或阅读器；卡片内不再放置“阅读”“制作 PPT”等重复操作按钮。
- MVP 不支持移除本地导入书籍，也不提供回收站；微信读书书籍同样不显示单书删除。
- 书架卡片不展示书籍来源标记或标签，避免低频来源信息干扰封面识别；来源筛选仍保留“全部 / 微信读书 / 我的导入”，书籍详情页的元信息明确显示“本地导入”或“微信读书同步”。
- 长书名和作者必须可识别且不能破坏书架扫描节奏；显示行数、截断和卡片高度由 Open Design 使用真实内容验证。

**阅读、笔记与单书工作区**

- 微信读书工作区只提供我的笔记、书友笔记、老己笔记和读书 PPT，不提供站内全文阅读。
- “我的笔记”和“书友笔记”以多条独立原文项展示，不在每条内容下常驻操作按钮；点击、轻触或键盘聚焦某一条后，才在该条附近显示“复制 / 写笔记”。
- 本地 EPUB/PDF 共用“目录 + 阅读区 + 老己笔记”阅读器外壳，不按文件类型设计两套界面。PDF 优先使用内置书签生成章节目录，没有书签时自动提取章节标题；无法可靠识别章节时才在同一目录区域内降级为页码/缩略页导航。小屏幕需保证目录、笔记和正文可以清晰切换且不互相遮挡，具体承载方式由 Open Design 决定。
- 所有书籍使用同一套详情页头、封面信息、标签栏和内容容器，只根据来源显示可用区域。微信读书显示“我的笔记 / 书友笔记 / 老己笔记 / 读书 PPT”；本地书显示“阅读 / 老己笔记 / 读书 PPT”。本地书的“老己笔记”区域同时汇总划线、有原文引用的笔记和无原文引用的笔记；微信读书的“老己笔记”只显示用户新增的笔记。
- 老己笔记不要求用户区分书籍级、章节级或划线级。系统只根据记录是否有关联原文决定展示：有划线就显示划线原文；划线附带笔记时同时显示原文和笔记；独立记录只显示笔记正文。只有用户创建的老己笔记可编辑和删除，引用原文保持只读。
- 删除老己笔记采用目标明确的确认对话框，只删除当前用户笔记，不删除关联原文、本地划线或书籍；失败时保留目标并允许重试，不能误删其他笔记。
- 微信读书同步内容和本地书原文始终只读；本地划线是用户创建的阅读标记，可通过“取消划线”移除高亮，但不因此删除已关联的老己笔记。

**对话式 PPT 闭环与状态恢复**

- PPT 不要求用户逐条勾选素材。专属会话先选择范围，再通过需求卡确认用途、受众和页数，随后生成大纲。
- 本地书支持整本书、章节或已有老己笔记；微信读书支持章节、已同步的我的笔记与老己笔记，书友观点必须由用户明确选择。
- 微信读书所选章节没有可用同步内容时阻止生成，并引导选择其他章节或改用全部笔记；不使用模型编造章节内容。
- 大纲至少保留一页；新增、删除、编辑或重新生成都会使旧确认失效。只有再次明确确认后才能进入最终生成。
- 模板选择和大纲内容持久保存。预览页读取实际页数和标题，生成失败保留已完成页、大纲和模板，并从失败处重试。
- 未确认大纲时，直接打开预览页也必须阻止生成和重试，并引导返回大纲确认。

**连接与高风险操作**

- AI 和微信读书连接统一覆盖未配置、验证中、已连接、失效、部分成功、失败、重试和撤销；取消或失败时保留原任务上下文。
- 退出登录和删除账户使用不同确认。删除账户必须输入当前密码，未满足条件时确认按钮不可用。

**统一状态规则**

- 数据页面不得把加载、网络失败或筛选为空误显示成真实空数据。
- 异步操作必须防止重复提交和过期任务回写；移除、替换或关闭任务后，旧异步结果不得继续覆盖当前状态。
- 弹窗打开后聚焦标题或首个指定控件，关闭后恢复到实际触发元素；标签页支持方向键、Home 和 End，并跳过禁用项。

## 0. 文档使用说明

本文档是老己 MVP 的唯一产品与交互事实来源。UI 依据本文档制作高保真设计稿，开发依据本文档理解页面行为、状态和验收结果。具体视觉参数、组件表现和响应式密度只在 `../ui/laoji-mvp-ui-design-spec.md` 中维护。

本文档描述“用户看到什么、可以做什么、操作后发生什么”，不包含框架、数据库、接口路由、部署或 PPT 渲染器等技术选型。

关联决策：`ADR-0001` 至 `ADR-0011`。当本文档与旧 PRD 冲突时，以本文档和状态为“已接受”的 ADR 为准；当行为规则与视觉规则发生冲突时，行为以本文档为准，视觉以 UI 设计规范为准。

## 1. 产品定义

### 1.1 一句话定义

老己是一个以聊天为主入口、以统一书架为内容入口的个人自我提升助理。MVP 聚焦一条闭环：

```text
微信读书同步 / 本地导入
        -> 阅读、划线、写老己笔记
        -> 在 PPT 对话中选择范围并生成大纲
        -> 用户确认
        -> 导出可编辑 PPTX
```

### 1.2 目标用户

需要持续学习、整理知识并形成输出的职场知识工作者。

### 1.3 MVP 目标

- 用户能在统一书架管理微信读书同步书和本地导入书。
- 用户能查找、阅读或查看书籍相关内容，并建立自己的私有笔记。
- 用户能从一本书的章节、划线和笔记生成 PPT 大纲。
- 用户确认大纲后，获得可预览、可再次打开、可下载的可编辑 PPTX。
- 所有核心流程在桌面和手机浏览器中可完成。

### 1.4 MVP 不包含

- 养生食谱、专注力管理等后续技能；
- 微信登录、手机号登录、邀请码；
- 多人协作、社区、公开分享、付费和订阅；
- 微信读书全文站内阅读；
- 微信读书全站书目搜索；
- 拼音搜索、全文搜索和笔记全文搜索；
- 跨书籍或跨来源混合生成 PPT；
- 通用的非读书 PPT 创作；
- 复杂阅读统计、社交排行和推荐系统。

## 2. 体验原则

1. **先使用，后配置**：注册后直接进入产品，不用配置卡阻塞用户。
2. **统一入口，能力真实**：两类书共用书架和工作区外壳，但只展示实际可用功能。
3. **熟悉但不复制**：借鉴微信读书的书架信息层级和封面网格，不复制品牌视觉、图标或资产。
4. **来源可追溯**：我的笔记、书友笔记和本地原文在界面中有明确来源。
5. **先确认，后生成**：PPT 必须经过大纲确认，不提供绕过确认的一键生成。
6. **安静、专注、工作导向**：不使用营销式首页、巨型口号或装饰性页面。
7. **错误可恢复**：连接、导入、同步和生成失败时保留上下文，并提供明确重试路径。

## 3. 信息架构

### 3.1 页面地图

```text
未登录
+-- AUTH-01 登录
+-- AUTH-02 注册
+-- AUTH-03 忘记密码 / 重置结果

已登录
+-- APP-01 对话
+-- BOOK-01 统一书架
|   +-- BOOK-02 统一书籍详情 · 微信读书内容变体
|   +-- BOOK-03 统一书籍详情 · 本地 EPUB 阅读变体
|   +-- BOOK-04 统一书籍详情 · 本地 PDF 阅读变体
|   +-- NOTE-01 老己笔记视图
|   +-- PPT-01 对话式 PPT 需求
|   +-- PPT-02 大纲确认
|   +-- PPT-03 模板、预览与作品
+-- SET-01 AI 服务
+-- SET-02 微信读书连接
+-- SET-03 账户与安全
```

### 3.2 全局导航

```text
已登录一级入口
+-- 对话
+-- 读书
+-- 设置
```

- 默认登录后进入 `对话`。
- 桌面、平板和手机都必须让三个一级入口清晰、可发现且可到达；具体使用侧栏、顶部导航、底部导航或其他主流方式，由 Open Design 根据视口与可用性决定。
- PPT 不作为顶层导航，从书籍工作区或书籍相关上下文进入。
- 设置在所有适用端都可从一级导航直接进入。

## 4. 核心用户流程

### F-01 注册与首次进入

```text
注册 -> 自动登录 -> 对话首页
                     |
                     +-- 顶部轻量提示“AI 未配置”
                     +-- 不展示配置向导或连接卡
```

### F-02 配置 AI 后返回原上下文

```text
用户触发 AI 操作
      -> 未配置提示
      -> 进入 AI 设置
      +-- 验证成功 -> 返回原页面和原操作上下文
      +-- 验证失败 -> 留在设置，可重试或取消
      +-- 取消配置 -> 返回原页面并保留原操作上下文
```

### F-03 连接微信读书

```text
书架 -> 同步微信读书
     -> 未连接状态
     -> 填写 Skill Key
     -> 验证并连接
     -> 同步中
     -> 书籍进入统一书架
```

### F-04 导入本地书

```text
书架 -> 导入书籍 -> 选择 EPUB / PDF
     -> 上传/解析中
     -> 成功：进入对应阅读器
     -> 不支持：说明原因并返回书架
```

### F-05 阅读和笔记

```text
本地正文 -> 选择原文 -> 选区旁浮动工具条：复制 / 划线 / 写笔记
         -> 书籍“老己笔记”汇总全书划线和老己笔记

微信读书内容 -> 激活一条同步原文 -> 复制 / 写引用型老己笔记
```

### F-06 书友观点加入 PPT

```text
书友笔记 -> 默认只读
         -> 用户选择“加入书友观点”
         -> 明确显示作者/来源
         -> 进入本次 PPT 范围
```

### F-07 PPT 生成

```text
书籍详情“制作 PPT” / 普通对话提出 PPT 制作意图
      -> 确定一本书并创建或绑定 PPT 专属会话
      -> 选择内容范围
      -> 确认用途/受众/页数需求卡
      -> 生成大纲
      -> 编辑并确认
      -> 预览并选择固定模板
      -> 生成与预览
      -> 下载可编辑 PPTX
```

### F-08 本地书保留

```text
本地书导入成功 -> 保留在书架
              -> 阅读 / 划线 / 写老己笔记 / 制作 PPT
```

MVP 不提供单书移除、回收站或恢复流程。

## 5. 页面原型说明

### 5.0 页面契约总表

页面详情中的原型、字段和状态与下表共同构成页面契约。UI 不得省略下表中的主要出口；开发不得在失败后丢失用户已输入内容或当前书籍上下文。

所有列表、标签页和数据工作区必须区分五类状态：初次加载、真实空数据、搜索/筛选为空、请求失败和正常数据。加载或失败不得短暂显示为空数据；每个空状态需要说明原因，并提供与当前状态直接相关的恢复动作。

| 页面 | 主要入口 | 页面完成结果 / 主要出口 | 页面级验收重点 |
| --- | --- | --- | --- |
| `AUTH-01` 登录 | 未登录访问、退出登录、注册页 | 登录成功进入 `APP-01`；可去注册或找回密码 | 凭证错误留在原页，邮箱不丢失 |
| `AUTH-02` 注册 | 登录页“注册” | 注册并自动登录后进入 `APP-01`；可返回登录 | 不出现邀请码、手机号、微信登录或配置向导 |
| `AUTH-03` 找回密码 | 登录页“忘记密码”、重置邮件 | 发送结果页或重置成功后返回 `AUTH-01` | 不泄露邮箱是否存在，失败可重试 |
| `APP-01` 对话 | 登录后默认页、主导航“对话”、新对话、书籍 PPT 入口 | 普通回复；切换会话；去 `BOOK-01`；从按钮或自然语言意图进入带单书上下文的 `PPT-01` | 每个会话独立保存输入、书籍上下文和任务；AI 未配置时保留输入和上下文 |
| `BOOK-01` 统一书架 | 主导航“读书”、对话中的“查看书架” | 打开 `BOOK-02/03/04`；去 `SET-02`；发起导入 | 区分加载、真实空书架、筛选为空和失败；两类来源能力不混淆 |
| `BOOK-02` 统一书籍详情 · 微信读书内容变体 | 微信读书书籍卡片 | 去 `NOTE-01` 或 `PPT-01`；返回书架 | 与本地书共用详情外壳；只显示微信读书可用区域，不出现站内全文阅读 |
| `BOOK-03` 统一书籍详情 · 本地 EPUB 阅读变体 | 本地 EPUB 书籍卡片 | 阅读、保存位置、划线或笔记；去 `NOTE-01/PPT-01` | 与微信读书/PDF 共用详情页头和内容容器；划线重开后仍对应相同原文 |
| `BOOK-04` 统一书籍详情 · 本地 PDF 阅读变体 | 本地 PDF 书籍卡片 | 阅读、保存位置、跨页划线或笔记；去 `NOTE-01/PPT-01` | 与微信读书/EPUB 共用详情页头和内容容器；优先显示章节目录 |
| `NOTE-01` 老己笔记视图 | 本地书“老己笔记”、微信读书“老己笔记”、阅读器写笔记 | 汇总当前书籍可见的老己笔记内容；定位原文；新建、编辑或删除老己笔记 | 作为统一书籍详情的内容区域展示；本地包含划线和带原文笔记，微信读书只显示新增笔记 |
| `PPT-01` 对话式 PPT 需求 | 书籍工作区“制作 PPT”、书籍“读书 PPT”分区、对话中的 PPT 制作意图 | 在绑定书籍的会话中确认范围与需求后生成大纲 | 一次仅一本书，不逐条选择素材，失败保留原消息、范围和需求 |
| `PPT-02` 大纲确认 | `PPT-01` 生成完成 | 确认后进入 `PPT-03`；可返回 PPT 对话 | 至少保留一页；未明确确认不得进入最终生成 |
| `PPT-03` 模板与作品 | 已确认的大纲、本书 PPT 历史 | 预览、下载 PPTX、返回编辑大纲或书籍 | 失败保留大纲、模板和已完成结果 |
| `SET-01` AI 服务 | 主导航“设置”、AI 未配置提示 | 验证并启用后返回原上下文或设置首页 | 全局仅一套生效供应商和 Key，可替换、撤销 |
| `SET-02` 微信读书连接 | 设置首页服务行、书架“同步微信读书” | 保存或测试 Key；测试成功后连接并同步；可清除凭证 | 未配置、已配置未测试、测试中、测试失败、已连接、失效、重试、撤销完整 |
| `SET-03` 账户与安全 | 主导航“设置” | 修改密码、退出或删除账户 | 不出现本地书回收站；账户级破坏性操作有确认 |

## AUTH-01 登录

**目标**：已有用户使用邮箱和密码进入老己。

```text

|              +--------------------------+                      |
|              | 邮箱                     |                      |
|              +--------------------------+                      |

|              +--------------------------+                      |
|              [ ] 保持登录    [忘记密码]                         |
|              +--------------------------+                      |
|              |          登录            |                      |
|              +--------------------------+                      |
|              还没有账户？[注册]                                 |
+----------------------------------------------------------------+
```

**手机原型**：

```text
+------------------------+
| 老己                   |
|                        |
| 欢迎回来               |
| [邮箱                 ] |
| [密码             眼  ] |
| [ ] 保持登录  忘记密码 |
| [      登录          ] |
| 还没有账户？注册       |
+------------------------+
```

**字段与操作**：

- 邮箱：必填，失焦后验证格式。
- 密码：必填，可显示/隐藏。
- 登录：字段合法后可点击；提交中按钮显示处理中并禁止重复提交。
- 登录成功：进入 `APP-01`。
- 登录失败：在表单内显示原因，不清空邮箱；密码错误时清空密码。

**状态**：初始、字段错误、提交中、凭证错误、网络错误、成功跳转。

**验收**：键盘可完成输入和提交；手机键盘弹出时登录按钮仍可到达；错误不使用只有颜色的提示。

## AUTH-02 注册

**目标**：通过邮箱和密码开放注册，不使用邀请码、手机号或微信登录。

**入口**：`AUTH-01` 的“注册”。

**桌面原型**：

```text
+----------------------------------------------------------------+
| 老己                                                           |
|                                                                |
|                    创建账户                                    |
|              [邮箱........................]                    |
|              [密码.................... 眼]                    |
|              [确认密码................ 眼]                    |
|              密码至少 8 个字符                                 |
|              [       注册并进入       ]                        |
|              已有账户？[登录]                                  |
+----------------------------------------------------------------+
```

**手机原型**：

```text
+------------------------+
| 老己                   |
|                        |
| 创建账户               |
| [邮箱................] |
| [密码............ 眼] |
| [确认密码........ 眼] |
| 密码至少 8 个字符      |
| [    注册并进入      ] |
| 已有账户？登录         |
+------------------------+
```

**规则**：

- 密码长度 8 至 64 个字符；确认密码必须一致。
- 注册提交中禁止重复操作。
- 注册成功后自动登录并进入 `APP-01`，不展示配置向导。
- 邮箱已注册时提供“去登录”和“忘记密码”。

**状态**：字段错误、邮箱已注册、注册中、网络错误、成功。

**出口与验收**：注册成功自动进入 `APP-01`；点击“登录”回到 `AUTH-01`。键盘可完成全表输入和提交，错误反馈不清空合法字段，页面不出现产品配置项。

## APP-01 对话首页

**目标**：作为老己的默认入口，承载可创建和切换的普通对话与书籍 PPT 专属会话。

**桌面原型**：

```text
+------------------+--------------------------------------+----------------+
| 老己  [+ 新对话] | 原子习惯：读书 PPT        AI 未配置 | 当前书籍       |
| 今天             +--------------------------------------+                |
| 原子习惯：PPT    | 老己：先选择内容范围。              | 原子习惯 42%   |
| 最近的阅读想法   | 用户：[我的笔记 + 老己笔记]          |                |
| 昨天             |                                      | 最近任务       |
| 深度工作笔记     | [需求卡：用途 / 受众 / 页数]         | 草稿 · 可继续  |
| 对话 / 读书 / 设置|                                     |                |
|                  | 输入消息...                    [发送] |                |
+------------------+--------------------------------------+----------------+
```

**手机原型**：

```text
+------------------------+
| [会话] 原子习惯：PPT AI 未配置 |
+------------------------+
| 对话内容               |
|                        |
| [选择书籍并生成 PPT]   |
|                        |
+------------------------+
| 输入消息...       [>]  |
+------------------------+
| 对话 | 读书 | 设置    |
+------------------------+
```

**信息与操作**：

- 桌面、平板和手机都提供“新对话”和按时间排列的会话列表；会话标题由首条用户消息生成，可重命名。会话列表的入口、位置和展开方式由 Open Design 决定。
- 小屏幕的会话管理不能长期挤压消息阅读和输入区域；关闭后应返回原会话位置，具体采用抽屉、弹窗、独立视图或其他主流方式由 Open Design 决定。
- 新对话默认没有书籍上下文；用户可主动选择书籍。书籍“制作 PPT”入口自动创建绑定该书的专属会话。
- 用户在普通对话中提出制作 PPT、生成读书分享或把某本书整理成 PPT 等明确意图时，触发 `PPT-01`，不要求必须先点击书籍页面按钮。
- 当前会话已有唯一书籍上下文时，直接将当前会话绑定为该书的 PPT 会话并进入范围选择；没有书籍上下文或书名不明确时，在当前对话显示书籍选择，选择后继续。不能仅凭模糊相似书名自动绑定。
- 当前消息提到多本书或匹配到同名不同来源书籍时，要求用户选择一本；MVP 不进入多书 PPT。
- AI 状态使用轻量文字、图标或等效表达，并在主要页面保持可发现；不使用大面积配置卡，具体位置由 Open Design 决定。
- 有历史的新对话显示最近阅读、最近任务和可执行命令，不展示营销文案。
- 首次进入且没有对话、书籍、笔记或最近活动时，显示简短起步说明，主动作是“打开书架”，次动作是“导入书籍”；不出现 AI 或微信读书配置卡。
- “查看书架”进入 `BOOK-01`。
- “生成读书 PPT”无论来自快捷入口还是用户消息，都要求最终绑定一本书。来自普通对话时优先继续使用当前会话，来自书籍详情按钮时创建新的 `PPT-01` 专属会话。
- 用户触发 PPT 制作但书架为空时，进入 `BOOK-01` 的真实空书架状态并保留原消息与创建意图；添加第一本书成功后显示“继续制作 PPT”，由用户确认后返回原会话继续。
- 带书籍上下文的对话必须显示当前绑定书籍，并提供最近阅读、最近笔记和最近作品的可发现入口；各端如何组织、展开和收起上下文由 Open Design 决定。
- AI 未配置时允许输入；点击发送后就地提示“配置 AI 后可使用对话”，提供“去配置”和“取消”。
- 配置成功、失败后取消或主动取消返回时，都保留未发送文字和当前书籍上下文；只有验证成功后 AI 操作才可继续。
- 删除会话只删除聊天记录；PPT 草稿、生成中任务和作品仍从书籍“读书 PPT”找回。
- 最近任务显示生成中、失败和已完成的 PPT；点击后回到对应书籍和作品状态，保证离开长任务页面后仍能找回任务。

**状态**：首次无任何数据、无当前会话但有最近内容、新对话、普通对话、识别到 PPT 意图、待选择书籍、同名/多书待确认、PPT 专属会话、回复生成中、回复失败、AI 未配置、Key 失效、书籍上下文、网络慢。

**验收**：对话只调度读书和 PPT；明确的 PPT 制作意图进入 `PPT-01`，书籍不明确时不误绑；其他未来技能不展示空入口；重复发送被阻止；失败消息可重试。

## BOOK-01 统一书架

**目标**：在一个入口查看、搜索和管理微信读书同步书及本地导入书。

**桌面原型**：

```text
+------------+-------------------------------------------------------+
| 老己       | 读书        AI 未配置·去配置        [同步] [导入]|
|            +-------------------------------------------------------+
|   对话     | [搜索书名或作者........] [全部|微信读书|我的导入]       |
| > 读书     +-------------------------------------------------------+
|   设置     | [封面]     [封面]     [封面]     [封面]               |
|            | 原子习惯   深度工作   被讨厌的勇气  思考，快与慢       |
|            | 进度 42%   18 条笔记    12 条划线    进度 28%            |
+------------+-------------------------------------------------------+
```

**手机原型**：

```text
+----------------------------+
| 读书             [同步][+] |
| [搜索书名或作者........]   |
| [全部|微信读书|我的导入]   |
+----------------------------+
| [封面]          [封面]     |
| 原子习惯        深度工作   |
| 42%             28%             |
+----------------------------+
| 对话 | 读书 | 设置        |
+----------------------------+
```

**书籍卡片**：

- 必须展示封面、书名和作者；书架卡片不显示“本地导入”或“微信读书同步”等来源标记、角标或标签。
- 微信读书进度或笔记数量、本地文件类型和阅读进度属于可选次级信息；显示时不得破坏当前紧凑卡片高度。
- 同名不同来源显示为两张卡片，不自动合并。
- 封面缺失或源图清晰度不足时使用稳定比例的文字封面；任何来源图片都不拉伸或超出清晰度上限放大。
- 书名和作者均为单行；溢出省略，不改变卡片高度。书籍详情页在作者、进度等元信息旁显示来源，供用户确认能力差异。

**搜索与筛选**：

- 搜索匹配书名或作者，输入后更新当前书架结果。
- 来源筛选为分段控件：全部、微信读书、我的导入。
- 当前原型固定按最近访问排序，不显示单独的排序控件。
- 搜索和筛选可叠加；清空搜索保留来源筛选。

**主要操作**：

- 同步：未连接进入 `SET-02`；已连接开始同步并在当前页显示状态。
- 导入：打开文件选择，限制 EPUB/PDF；选择后显示上传/解析进度。
- 点击微信读书卡片进入 `BOOK-02`。
- 点击任意书籍都进入统一书籍详情外壳。微信读书使用 `BOOK-02` 内容变体；本地 EPUB/PDF 使用 `BOOK-03/04` 阅读内容变体，但页头、封面信息、标签样式和内容容器保持一致。
- MVP 不提供任何单书移除入口。

**状态**：初次加载、首次空书架、已连接但同步结果为空、当前来源筛选为空、仅微信读书、仅本地书、同步中、部分同步失败、导入中、导入失败、搜索无结果、加载更多、网络错误。

**缺省与失败状态**：

| 状态 | 界面说明 | 主要动作 | 次要动作 |
| --- | --- | --- | --- |
| 初次加载 | 使用稳定骨架，不显示“书架为空” | 等待 | 无 |
| 首次空书架且未连接 | 说明可以同步微信读书或导入本地书 | 导入书籍 | 连接微信读书 |
| 已连接但同步结果为空 | 说明当前账号尚未同步到书籍，不误报失败 | 重新同步 | 导入书籍 |
| 当前来源筛选为空 | 说明当前来源没有书，但保留其他来源数量 | 查看全部 | 添加当前来源书籍 |
| 搜索无结果 | 显示当前搜索词，不发起外部搜索 | 清除搜索 | 调整来源筛选 |
| 网络错误且无缓存 | 说明书架暂时无法加载，不显示空书架文案 | 重试 | 无 |
| 网络错误但有缓存 | 保留已有书籍并显示非阻塞错误 | 重试 | 继续浏览 |

这些空状态只在用户进入书架后出现，不在注册成功后的对话首页提前展示连接卡。

## BOOK-02 统一书籍详情 · 微信读书内容变体

**目标**：在统一书籍详情外壳中查看微信读书同步的我的笔记、书友笔记、老己笔记和读书 PPT；不提供站内全文阅读。页头、封面信息、标签栏和内容容器与本地书详情使用同一组件。

**桌面原型**：

```text
+------------+-------------------------------------------------------+
| 读书       | [返回书架]  [封面] 原子习惯                           |
|            |          詹姆斯·克利尔  微信读书  进度 42%   [同步] [制作 PPT] |
|            +-------------------------------------------------------+
|            | [我的笔记] [书友笔记] [老己笔记] [读书 PPT]            |
|            +-------------------------------------------------------+
|            | 我的划线 128 条                                      |
|            | “每个行动都是一次投票……”                              |
|            | “习惯是自我身份的复利……”                            |
|            | “让行动变得显而易见……”                              |
+------------+-------------------------------------------------------+
```

**手机原型**：

```text
+------------------------+
| < 原子习惯       [同步] [制作 PPT]|
| 微信读书  进度 42%     |
| [我的笔记][书友笔记][老己笔记][读书 PPT]|
+------------------------+
| 原文条目 1             |
| 原文...                |
| 点击条目后在附近显示 [复制] [写笔记] |
| 原文条目 2             |
| 原文...                |
+------------------------+
```

**内容分区**：

- 我的笔记：我的划线和我的想法；同步内容只读，可新建引用型老己笔记。
- 书友笔记：最多展示 20 条热门划线和 20 条高赞评价；内容只读，可新建引用型老己笔记。标签始终保留；真实没有内容时显示空状态，确认有内容但获取失败时显示失败与重试。
- 老己笔记：使用 `NOTE-01` 结构统一展示用户记录；有原文引用时显示原文和来源，没有原文引用时只显示笔记正文。
- 读书 PPT：本书 PPT 草稿、生成中、失败任务和已完成作品；主动作是“制作 PPT”。

**标签页缺省状态**：

| 标签页 | 空状态说明 | 主要动作 |
| --- | --- | --- |
| 我的笔记 | 暂无同步的个人划线或想法 | 立即同步 |
| 书友笔记 | 暂无可展示的书友笔记 | 返回我的笔记 |
| 书友笔记 | 确认有内容但本次获取失败 | 重试失败部分 |
| 老己笔记 | 还没有老己笔记 | 新建书籍笔记 |
| 读书 PPT | 还没有 PPT 草稿或作品 | 制作 PPT |

同步部分失败时，只在受影响的标签页显示失败范围和“重试失败部分”，其他已成功内容保持可用。

**原文条目操作**：

- 我的笔记和书友笔记都按多条独立内容项展示；每条保留原文、章节/位置、内容类型和作者信息（接口有值时）。
- 默认只显示内容，不在每条下方重复放置按钮。点击、轻触或键盘激活某一条后，在该条附近显示上下文工具条：`复制`、`写笔记`；一次只允许一个条目处于激活状态。
- `复制`只复制当前条目的正文，不附带界面标签；成功后显示短暂“已复制”反馈，不需要 AI 配置。
- `写笔记`创建引用当前条目的老己笔记，编辑器同时显示只读引用原文；同一条原文可以新增多条老己笔记。
- 点击条目外、按 `Esc` 或切换标签页时收起工具条。桌面端拖选文字时优先完成文本选择，不因按下鼠标立即触发工具条。

**明确限制**：不出现“开始阅读”“继续阅读”或正文翻页入口。可以显示进度，但不能暗示老己拥有全文。

**书友内容操作**：

- 书友观点默认不进入 PPT；只有在 PPT 专属会话中明确选择“加入书友观点”才可使用。
- 加入后在大纲和最终作品中显示作者、来源和“书友观点”。
- 不能编辑他人原文；可以另建私有引用型老己笔记。

**状态**：同步中、同步成功、部分内容失败、连接失效、无我的笔记、无书友笔记、书友笔记获取失败、网络错误。

**目标**：在与微信读书和 EPUB 一致的书籍详情外壳中阅读 PDF；只在“阅读”区域增加必要的页码、缩放和渲染控件，不改变详情页结构。

```text
+--------------+--------------------------------------+---------------+
| [封面] 书名 / 作者 / 本地导入 / 进度                     [制作 PPT]   |

| 第三章         | ------------------------------------ | 第12-13页     |
|              | 页面 13：选区在本页继续并结束        | 老己笔记      |
|              | [复制] [划线] [写笔记]                | [保存]        |

```

**手机原型**：

```text
+------------------------+
| [目录] 12/236 [-]100%[+]|
| [阅读][老己笔记][读书PPT]  |
+------------------------+
| 第 12 页               |

| 第 13 页               |
| 页面内容...            |
+------------------------+
| 选中文本后在选区附近显示 [复制][划线][写笔记] |
+------------------------+
```

**交互**：

- PDF 导入解析目录的顺序固定为：读取文件内置书签/大纲；没有可用大纲时，根据文本层中的标题字号、层级和位置自动提取章节标题；提取结果不可靠时不生成虚假章节。
- 目录面板默认展示章节层级并定位到对应页。只有未识别到可靠章节时，目录面板才显示“未识别到章节”，并提供页码列表/缩略页导航作为降级能力。
- 自动提取目录属于本地文档解析，不依赖用户配置 AI API Key；解析中显示“正在识别目录”，失败不阻塞 PDF 阅读。
- 允许选区从一页末尾跨到下一页或多页，并作为一条连续划线保存。
- 选区工具条与 EPUB 一致，包含复制、划线和写笔记；跟随选区出现并避让页码、浏览器边缘和手机安全区，不固定在页面底部。点击已有划线时提供复制和写笔记。
- 页面缩放、适合宽度、页码跳转不改变已保存划线位置。
- 重新打开后恢复跨页高亮；若无法准确恢复，显示“需要重新定位”，不静默标到错误文字。

**不支持状态**：

| 文件情况 | 产品行为 |
| --- | --- |
| 扫描版 PDF | 允许查看可渲染页面；禁用精准划线并说明原因 |
| 无文本层/文本层损坏 | 允许查看；禁用精准划线 |
| 加密且无法读取 | 阻止导入，说明 MVP 暂不支持 |
| 文本顺序异常 | 提示精准划线不可用，不承诺错误结果 |

**验收**：跨页选区在缩放、刷新和重新打开后仍对应相同原文；所有不支持状态在用户开始大量阅读前可见。

**状态**：文件加载中、正在识别目录、内置目录可用、自动目录可用、未识别到章节、页面渲染中、正常阅读、跨页选区、保存中、保存失败、页面渲染失败、无可渲染页面、需要重新定位、不支持精准划线。

- 页面渲染失败保留书名、页码和返回书架入口，提供“重试加载”。
- 无可渲染页面不显示空白阅读区；说明文件无法显示，并提供“返回书架”。
- 扫描版或文本层异常属于“可阅读但不可精准划线”，不得与渲染失败或空文件混为同一状态。
- 未识别到章节不等于文件解析失败；用户仍可按页阅读、定位、划线和写笔记。

## NOTE-01 老己笔记视图

**目标**：在统一书籍详情中展示当前来源可见的老己笔记。微信读书只显示用户新增的笔记；本地书同时显示全书划线和用户笔记。记录有原文引用时显示原文与笔记，没有原文引用时只显示笔记正文。阅读器内的笔记入口仍只承担当前上下文的快速查看和编辑。

**桌面原型（本地书变体）**：

```text
+--------------------------------------------------------------------+
| 老己笔记  [全部] [划线] [笔记]                         [新建笔记] |
+--------------------------------------------------------------------+
| 第三章 · 位置 36%                                  [回到原文]     |
| “系统不会上升到目标的高度，而会下降到系统的水平。”                 |
|                                               [复制] [写笔记]     |
+--------------------------------------------------------------------+
| 第五章 · 老己笔记                                  [回到原文]     |
| 把目标拆成环境提示和最小动作。                    [编辑] [删除]   |
+--------------------------------------------------------------------+
```

**手机原型（本地书变体）**：

```text
+------------------------+
| 老己笔记      [筛选][+]|
| [全部] [划线] [笔记]   |
+------------------------+
| 第三章                  |
| 原文...                |
| [回到原文]             |
+------------------------+
```

**规则**：

- 本内容区嵌入统一书籍详情外壳，不另起一套页面头部。两类书都从“老己笔记”进入，但内容规则按来源自适应。
- “全部 / 划线 / 笔记”只属于本地书变体；它们是内容查看筛选，不代表用户需要维护书籍级、章节级或划线级笔记分类。微信读书变体直接显示用户新增的老己笔记列表与新建入口，不显示“划线”筛选。
- 本地书默认显示“全部”，同时包含所有划线和用户笔记；“划线”只筛选划线，“笔记”只筛选用户笔记。每条有原文引用时显示原文、章节/页码或进度位置以及“回到原文”，没有原文引用时只显示笔记正文。
- 激活某条划线后显示复制、写笔记；取消划线放在次级菜单。点击“回到原文”进入阅读器并定位、短暂强调对应原文。
- 本地“笔记”筛选按最近更新时间展示用户笔记；有原文引用时显示原文、来源、作者（如有）和位置，没有原文引用时只显示笔记正文。同一原文可以关联多条用户笔记。
- 微信读书只显示用户新增的老己笔记，不将同步的“我的笔记”或“书友笔记”混入；有原文引用时显示关联原文和来源，没有原文引用时只显示笔记正文。
- 点击“新建笔记”创建不带原文引用的独立老己笔记；编辑器不要求选择书籍级、章节级或划线级归属，保存后只显示用户输入的笔记正文。
- 微信读书与本地书中的每条用户创建笔记都提供编辑和删除；编辑复用笔记编辑器并保留只读引用原文，同一原文可关联多条用户笔记。
- 删除前明确提示“只会删除这条老己笔记”，确认后只移除当前用户笔记，不影响同步内容、关联原文、本地划线或书籍；删除失败时保留该条笔记并允许重试。
- 汇总页不是 PPT 素材勾选器，不显示“加入 PPT”；制作 PPT 统一从“读书 PPT”、书籍主按钮或对话意图进入。

**状态**：初次加载、无老己笔记、仅有划线、筛选无结果、编辑中、保存中、保存失败、删除确认、删除中、删除失败、引用来源已失效、原文定位失败、网络错误。

- 真正无笔记时说明“还没有老己笔记”，主动作是“新建书籍笔记”，次动作是“返回阅读”。
- 本地只有划线且没有新增笔记时，默认“全部”仍展示划线；“笔记”筛选显示“还没有老己笔记”，主动作是“新建书籍笔记”，次动作是“继续阅读”。
- 筛选无结果时保留当前筛选条件，主动作是“清除筛选”，不显示创建引导。
- 初次加载和网络错误不得短暂显示“还没有笔记”。

## PPT-01 对话式 PPT 需求

**目标**：承接书籍“制作 PPT”、书籍“读书 PPT”分区或普通对话中的 PPT 制作意图，在绑定当前书籍的老己对话中用两轮引导确定生成范围和需求，不要求逐条选择素材。

**桌面/手机结构**：

```text
已选择《原子习惯》 · 制作读书 PPT

老己：先选择内容范围。
[整本书] [选择章节] [已有老己笔记]

老己：确认这份 PPT 的用途。
+-------------------------------------------+
| 主题/标题：原子习惯的核心方法               |
| 用途：读书分享                              |
| 分享对象：对本书不了解的听众                 |
| 页数：8 / 12 / 16 / 自定义                  |
|                         [生成大纲]           |
+-------------------------------------------+
```

**两轮引导**：

- 从普通对话触发时，用户原消息保留为本次任务要求；书籍确定后直接进入第一轮，不要求用户重复描述“制作 PPT”。
- 第一轮选择范围。本地书提供整本书、选择章节、已有老己笔记；微信读书提供选择章节、我的笔记 + 老己笔记和指定笔记范围。指定笔记范围按章节和内容类型筛选，不逐条勾选笔记。
- 微信读书只有在同步数据提供可靠章节元数据时才显示“选择章节”；没有章节元数据时隐藏该选项，并引导使用“我的笔记 + 老己笔记”。
- 书友观点默认不使用；用户在微信读书范围中明确选择“加入书友观点”后才纳入，并在大纲中保留来源。
- 第二轮以需求卡集中确认主题/标题、用途、分享对象和页数。主题/标题默认由老己根据书名和范围生成，用户可以修改；用途和分享对象提供可修改建议值；页数默认 12 页，提供 8、12、16 和自定义。
- 书籍由入口预选，MVP 不允许添加第二本书。后续多书合并不属于本次范围。
- 用户可以在对话中补充要求；需求卡与消息共同写入同一份草稿。

**按钮与状态规则**：

- AI 未配置时，用户可先完成范围和需求；点击“生成大纲”后就地提示配置 AI，成功后返回同一专属会话并保留草稿。
- 微信读书所选章节没有可用同步内容时，阻止生成并提供“选择其他章节”和“改用全部笔记”；如果没有可靠章节元数据，则不显示章节选择，不把空范围交给模型。
- 本地书整本或章节解析失败、范围加载失败和 AI 生成失败都保留需求卡与当前范围，并提供重试。
- 状态包括：识别到 PPT 意图、待选择书籍、书籍歧义、范围选择中、需求待确认、AI 未配置、内容不足、加载失败、生成中、生成失败和重复提交阻止。

- 知识卡片：强调观点、引用和行动项。
- 图文叙事：强调章节脉络和配图。
- 模板卡必须提供真实页面密度的预览；不以渐变色块或抽象装饰代替版式预览。

**生成状态**：

```text
待生成 -> 生成中 -> 可预览/可下载
                 -> 失败 -> 重试
```

- 生成中显示当前阶段和已完成页数，不承诺精确剩余时间。
- 失败保留大纲和用户编辑，不要求重新选素材。
- 返回大纲后再次生成会创建新版本，旧作品仍可打开。
- 本书“读书 PPT”分区展示草稿、生成中、失败任务和已完成作品：名称、模板、更新时间、状态、预览和下载。
- 删除对话不会删除本书 PPT 草稿或作品。
- 本书没有草稿或历史作品时显示“还没有读书 PPT”和“制作 PPT”；加载中或加载失败不得使用空作品文案。

## SET-01 AI 服务设置

**目标**：只配置一个当前生效的 AI 供应商和一把 API Key。

**桌面/手机表单**：

```text
+------------------------------------------+
| AI 服务                                 |
| 状态：未配置 / 验证中 / 已启用 / 失败    |
|                                          |
| 供应商 [DeepSeek v]                      |
| API Key [************************] [眼]    |
|                                          |
| [验证并启用]                             |
|                                          |
| 已配置时：[替换 Key] [撤销配置]           |
+------------------------------------------+
```

**规则**：

- 供应商选项：DeepSeek、Kimi、GLM。
- 不展示具体模型选择。
- 验证成功后显示可用能力状态；未验证能力不显示为可用。
- 替换 Key 先验证新 Key，成功后才替换旧配置。
- 撤销配置需确认；撤销后阅读和笔记仍可用，AI 操作恢复未配置提示。
- 从某个 AI 操作进入设置时，成功后返回原上下文。
- 验证失败后用户可以继续修改并重试，或取消返回原页面；取消不丢失原操作上下文。

## SET-02 微信读书连接设置

**目标**：从设置首页或书架入口配置、测试和撤销微信读书 Skill Key。

```text
+------------------------------------------+
| 微信读书                                |
| 连接微信读书官方 Skill API，导入书架、划线和想法 |
| 状态：未配置 / 已配置 / 测试中 / 已连接 / 已失效 |
|                                          |
| API Key（微信读书 Skill Key） [********] [眼] |
| [保存] [测试]                             |
|                                          |
| 最近同步：2026-08-03 14:20               |
| [立即同步] [修改 Key] [清除凭证]          |
+------------------------------------------+
```

**规则**：

- 不提供二维码或微信登录按钮。
- 设置首页的“管理”和书架的“同步微信读书”都进入本页；不在注册后主动弹出配置卡。
- `保存`只保存当前 Key，不开始同步，也不代表连接测试成功；`测试`验证 Key，成功后状态变为“已连接”，才允许同步。
- 已保存但尚未测试成功时显示“已配置”，保留 Key 的掩码和“测试”主操作；测试失败保留输入并提供重试。
- 验证失败保留输入并说明可操作原因，不展示第三方原始错误码。
- 清除凭证需确认；停止后续同步，已同步内容保留只读。
- 重新同步按微信读书外部稳定标识更新已有内容，不重复创建；外部内容不再返回时保留本地快照并标记来源失效，不删除用户创建的老己笔记。
- 更换 Skill Key 后，新账号数据不与旧账号自动合并；旧账号已同步内容继续保留为只读，用户可在书架来源和详情元信息中区分。
- 微信读书单书在 MVP 不提供移除；账户删除时统一删除用户数据。

## SET-03 账户与安全

**目标**：管理个人资料、AI 与微信读书服务、登录状态和账户删除。

**结构**：

```text
设置首页
+-- 个人资料
+-- 已连接的服务
|   +-- AI 服务                 [状态] [管理]
|   +-- 微信读书                [状态] [管理]
+-- 存储、安全与退出
    +-- 邮箱 / 修改密码 / 退出登录
    +-- 删除账户

```

**规则**：

- 删除账户是独立高风险操作，需密码确认并说明会删除账户数据和作品。
- MVP 不提供本地书移除、回收站、恢复或永久删除；设置页不得为这些未来能力预留入口或说明。
- “微信读书”服务行的“管理”进入 `SET-02`；书架的“同步微信读书”在未连接或连接失效时也进入同一页面。

| 搜索 | 无结果 | 不发起外部搜索 | 清除、改变筛选 |

| 本地划线汇总 | 空 | 说明全书尚无划线 | 继续阅读 |

| PPTX | 完成 | 显示预览和作品记录 | 下载、再次打开 |
| 读书 PPT | 空 | 说明尚未创建草稿或作品 | 制作 PPT |

### 重复操作规则

- 所有提交型按钮在处理中禁用，反馈切换不得造成主要操作区明显跳动。
- 重试复用原任务和用户输入，不创建不可区分的重复记录。
- 用户离开长任务页面后，任务继续显示在对应书籍的状态区域，并同步出现在 `APP-01` 最近任务中；任务完成、失败或被删除后两处状态保持一致。

## 7. 响应式规则

### 7.1 覆盖范围

- 桌面、平板和手机浏览器都必须完成核心流程；断点、导航承载、分栏数量和内容重排方式由 UI 设计规范与 Open Design 根据真实视口验证。
- 大屏应支持高效扫描和并行查看相关信息；小屏应优先当前任务，并让次级内容可发现、可切换、可返回。

### 7.2 共同行为

- 手机端不依赖悬停；图标按钮有可见标签或辅助说明。
- 触控目标满足可用性与可访问性要求；操作条和工具栏在状态切换时保持稳定。
- 书架在各视口都优先保证快速扫描、封面清晰和书名可识别；列数、卡片宽度、标题行数与间距由 Open Design 通过真实内容验证，不能放大低清封面填满空间。
- 小屏阅读时，目录、上下文笔记和正文不得互相遮挡；具体切换与承载方式由 Open Design 决定。
- 所有导航和浮层避开系统安全区，不遮挡当前任务；选中态清晰且不只依赖颜色。
- 微信读书原文条目激活后和本地阅读文本选中后，操作条贴近当前内容并自动上下避让；它不得成为脱离当前内容的常驻工具栏。
- PPT 大纲在小屏上必须支持查看、编辑、调整顺序、查看来源和确认；具体采用逐页、列表、面板或其他主流方式由 Open Design 决定。
- 书名、作者和进度等信息在各视口都可辨认，长文本不会覆盖其他信息；截断与换行方式由 Open Design 决定。
- 键盘弹出时，当前输入和主要提交按钮可滚动到可见区域。
- 同一任务一次只呈现一个主要浮层层级，避免弹窗、抽屉或面板相互嵌套。

## 9. UI 设计输入

### 9.1 视觉方向

- 已接受方向为“青瓷书斋”：清新、安静、有书卷气，以现代工作台为骨架，以克制的国风细节建立识别。
- 国风元素使用“己”字题签、活字印刷字模暗纹、青瓷色和阅读排版；不使用大面积水墨、仿古纸纹或无功能含义的装饰性分组标题。
- 书架以封面为第一识别信号，文本信息用于辅助识别书籍和进度。
- 书架卡片不展示任何来源图形、角标或文字标签；来源筛选器承担筛选职责，书籍详情、笔记和 PPT 引用中以清晰元信息追溯来源。
- 所有已登录主页面提供可发现但不抢占主任务的 AI 配置弱提示，显示未配置、当前供应商或凭证失效状态；点击进入 `SET-01` 并保留当前上下文，具体位置由 Open Design 决定。
- 阅读区优先保证文本宽度、行距和选区清晰度。
- AI 状态和配置提示保持轻量，不做大卡片或强制向导。
- 卡片仅用于书籍、笔记、作品等重复实体；页面区块不包装成多层卡片。

上述方向的色值、字体、封面尺寸、网格密度和组件状态以 `../ui/laoji-mvp-ui-design-spec.md` 为唯一事实源，本文不复制具体参数。

### 9.2 UI 需输出的页面状态

UI 设计稿至少覆盖：

- 15 个页面的桌面主状态和手机主状态；
- 统一书架的空、正常、搜索无结果、同步中；
- 微信读书未连接、连接失效；
- AI 未配置和配置失败；
- EPUB 正文选区；
- PDF 跨页选区和不支持精准划线；
- 微信读书我的笔记/书友笔记多条列表、单条激活工具条，以及本地书已有划线激活工具条；
- 老己笔记编辑和书友观点选中；
- 对话新建与切换、对话式 PPT 范围选择、需求卡、大纲、生成中、失败和完成；
- 账户级破坏性操作确认。
- 首次无任何数据、来源筛选为空、同步结果为空、无我的笔记、书友笔记获取失败、无老己笔记和无读书 PPT。

### 9.3 设计参考边界

微信读书和 Alice APP 只作为交互习惯和信息层级参考。2026-08-08 提供的参考图仅用于确认“激活一条原文后，在内容附近显示上下文工具条”的交互关系；不照搬其黑色工具条、字号、颜色或品牌视觉。本 PRD 与 UI 规范中的文字规则可以独立完成高保真设计。

## 12. 原型冻结规则

- UI 可以调整视觉层级、排版和组件表现，但不能改变页面职责、来源能力和已接受流程。
- UI 发现内容溢出或移动端不可用时，优先调整布局，不删除产品状态。
- 开发发现技术不可行时，先回到对应阶段 0 验证结论，不在实现中静默降级产品承诺。
- 新增功能必须先判断是否属于 MVP；不在范围内的内容进入后续版本清单，不直接塞进当前页面。
