- 版本：Prototype PRD v1.2
- 状态：UI 设计与开发的产品输入
- 日期：2026-08-03；2026-08-04 同步已确认 UI 决策与缺省状态审查
- 适用端：响应式 Web，覆盖桌面、平板和手机
- 目标读者：UI 设计师、产品、前端、后端、测试和后续 agent

## 0. 文档使用说明

本文档是老己 MVP 的唯一产品与交互事实来源。UI 依据本文档制作高保真设计稿，开发依据本文档理解页面行为、状态和验收结果。具体视觉参数、组件表现和响应式密度只在 `../ui/laoji-mvp-ui-design-spec.md` 中维护。

本文档描述“用户看到什么、可以做什么、操作后发生什么”，不包含框架、数据库、接口路由、部署或 PPT 渲染器等技术选型。

关联决策：`ADR-0001` 至 `ADR-0011`。当本文档与旧 PRD 冲突时，以本文档和状态为“已接受”的 ADR 为准；当行为规则与视觉规则发生冲突时，行为以本文档为准，视觉以 UI 设计规范为准。

## 1. 产品定义

### 1.1 一句话定义

老己是一个以聊天为主入口、以统一书架为内容入口的个人自我提升助理。MVP 聚焦一条闭环：

```text
微信读书同步 / 本地导入
        -> 阅读、划线和笔记
        -> 选择素材并生成大纲
        -> 用户确认
        -> 导出可编辑 PPTX
```

### 1.2 目标用户

需要持续学习、整理知识并形成输出的职场知识工作者。

### 1.3 MVP 目标

- 用户能在统一书架管理微信读书同步书和本地导入书。
- 用户能查找、阅读或查看书籍相关内容，并建立自己的私有笔记。
- 用户能从一本书的章节、划线和笔记生成 PPT 大纲。
- 用户确认大纲后，获得可预览、可再次打开、可下载的可编辑 PPTX。
- 所有核心流程在桌面和手机浏览器中可完成。

### 1.4 MVP 不包含

- 养生食谱、专注力管理等后续技能；
- 微信登录、手机号登录、邀请码；
- 多人协作、社区、公开分享、付费和订阅；
- 微信读书全文站内阅读；
- 微信读书全站书目搜索；
- 拼音搜索、全文搜索和笔记全文搜索；
- 跨书籍或跨来源混合生成 PPT；
- 通用的非读书 PPT 创作；
- 复杂阅读统计、社交排行和推荐系统。

## 2. 体验原则

1. **先使用，后配置**：注册后直接进入产品，不用配置卡阻塞用户。
2. **统一入口，能力真实**：两类书共用书架和工作区外壳，但只展示实际可用功能。
3. **熟悉但不复制**：借鉴微信读书的书架信息层级和封面网格，不复制品牌视觉、图标或资产。
4. **来源可追溯**：个人内容、公开参考和本地原文在界面中有明确来源。
5. **先确认，后生成**：PPT 必须经过大纲确认，不提供绕过确认的一键生成。
6. **安静、专注、工作导向**：不使用营销式首页、巨型口号或装饰性页面。
7. **错误可恢复**：连接、导入、同步和生成失败时保留上下文，并提供明确重试路径。

## 4. 核心用户流程

### F-01 注册与首次进入

```text
注册 -> 自动登录 -> 对话首页
                     |
                     +-- 顶部轻量提示“AI 未配置”
                     +-- 不展示配置向导或连接卡
```

### F-02 配置 AI 后返回原上下文

```text
用户触发 AI 操作
      -> 未配置提示
      -> 进入 AI 设置
      +-- 验证成功 -> 返回原页面和原操作上下文
      +-- 验证失败 -> 留在设置，可重试或取消
      +-- 取消配置 -> 返回原页面并保留原操作上下文
```

### F-03 连接微信读书

```text
书架 -> 同步微信读书
     -> 未连接状态
     -> 填写 Skill Key
     -> 验证并连接
     -> 同步中
     -> 书籍进入统一书架
```

### F-04 导入本地书

```text
书架 -> 导入书籍 -> 选择 EPUB / PDF
     -> 上传/解析中
     -> 成功：进入对应阅读器
     -> 不支持：说明原因并返回书架
```

### F-05 阅读和笔记

```text
本地正文 -> 选择原文 -> 划线 / 添加备注 / 加入 PPT

微信读书内容 -> 查看同步原文 -> 添加老己补充 / 加入 PPT
```

### F-06 公开内容加入 PPT

```text
公开参考 -> 默认只读
         -> 用户点击“作为参考素材”
         -> 明确显示作者/来源
         -> 加入本书 PPT 素材集合
```

### F-07 PPT 生成

```text
选择一本书和素材
      -> 填写用途/受众/页数/PPT 备注
      -> 生成大纲
      -> 编辑并确认
      -> 选择模板和配图
      -> 生成与预览
      -> 下载可编辑 PPTX
```

### F-08 移除和恢复本地书

```text
本地书菜单 -> 移除 -> 确认
           -> 进入 30 天回收站
           -> 恢复 / 永久删除

已生成 PPT 始终保留，除非用户单独删除 PPT 作品。
```

## 5. 页面原型说明

### 5.0 页面契约总表

页面详情中的原型、字段和状态与下表共同构成页面契约。UI 不得省略下表中的主要出口；开发不得在失败后丢失用户已输入内容或当前书籍上下文。

所有列表、标签页和数据工作区必须区分五类状态：初次加载、真实空数据、搜索/筛选为空、请求失败和正常数据。加载或失败不得短暂显示为空数据；每个空状态需要说明原因，并提供与当前状态直接相关的恢复动作。

| 页面 | 主要入口 | 页面完成结果 / 主要出口 | 页面级验收重点 |
| --- | --- | --- | --- |
| `AUTH-01` 登录 | 未登录访问、退出登录、注册页 | 登录成功进入 `APP-01`；可去注册或找回密码 | 凭证错误留在原页，邮箱不丢失 |
| `AUTH-02` 注册 | 登录页“注册” | 注册并自动登录后进入 `APP-01`；可返回登录 | 不出现邀请码、手机号、微信登录或配置向导 |
| `AUTH-03` 找回密码 | 登录页“忘记密码”、重置邮件 | 发送结果页或重置成功后返回 `AUTH-01` | 不泄露邮箱是否存在，失败可重试 |
| `APP-01` 对话 | 登录后默认页、主导航“对话” | 普通回复；去 `BOOK-01`；带单书上下文进入 `PPT-01` | 首次无数据仍有明确起点；AI 未配置时保留输入和上下文 |
| `BOOK-01` 统一书架 | 主导航“读书”、对话中的“查看书架” | 打开 `BOOK-02/03/04`；去 `SET-02`；发起导入 | 区分加载、真实空书架、筛选为空和失败；两类来源能力不混淆 |
| `BOOK-02` 微信读书工作区 | 微信读书书籍卡片 | 去 `NOTE-01` 或 `PPT-01`；返回书架 | 不出现站内全文阅读入口 |
| `BOOK-03` EPUB 阅读器 | EPUB 书籍卡片 | 保存阅读位置、划线或备注；去 `NOTE-01/PPT-01` | 划线重开后仍对应相同原文 |
| `BOOK-04` PDF 阅读器 | PDF 书籍卡片 | 保存跨页划线或备注；去 `NOTE-01/PPT-01` | 不支持精准划线时提前说明并禁用相关动作 |
| `NOTE-01` 统一笔记 | 书籍工作区“笔记”、阅读器笔记面板 | 保存私有补充、加入 PPT、返回当前书籍 | 来源内容只读，公开参考必须显式选择 |
| `PPT-01` 素材与要求 | 书籍工作区“新建 PPT”、对话技能触发 | 生成大纲后进入 `PPT-02`；可返回当前书籍 | 一次仅一本书，失败保留素材和要求 |
| `PPT-02` 大纲确认 | `PPT-01` 生成完成 | 确认后进入 `PPT-03`；可返回素材页 | 至少保留一页；未明确确认不得进入最终生成 |
| `PPT-03` 模板与作品 | 已确认的大纲、本书 PPT 历史 | 预览、下载 PPTX、返回编辑大纲或书籍 | 失败保留大纲、模板和已完成结果 |
| `SET-01` AI 服务 | 主导航“设置”、AI 未配置提示 | 验证并启用后返回原上下文或设置首页 | 全局仅一套生效供应商和 Key，可替换、撤销 |
| `SET-02` 微信读书连接 | 设置、书架“同步微信读书” | 连接并同步后返回书架；可清除凭证 | 未连接、验证中、失败、失效、重试、撤销完整 |
| `SET-03` 账户与回收站 | 主导航“设置” | 恢复或永久删除本地书、退出或删除账户 | 空回收站有明确说明；破坏性操作有确认，30 天恢复路径明确 |

## AUTH-01 登录

**目标**：已有用户使用邮箱和密码进入老己。

**入口**：未登录访问产品、退出登录后、注册页“已有账户”。

**桌面原型**：

```text
+----------------------------------------------------------------+
| 老己                                                           |
|                                                                |
|                    欢迎回来                                    |
|              +--------------------------+                      |
|              | 邮箱                     |                      |
|              +--------------------------+                      |
|              | 密码                 [眼] |                      |
|              +--------------------------+                      |
|              [ ] 保持登录    [忘记密码]                         |
|              +--------------------------+                      |
|              |          登录            |                      |
|              +--------------------------+                      |
|              还没有账户？[注册]                                 |
+----------------------------------------------------------------+
```

**手机原型**：

```text
+------------------------+
| 老己                   |
|                        |
| 欢迎回来               |
| [邮箱                 ] |
| [密码             眼  ] |
| [ ] 保持登录  忘记密码 |
| [      登录          ] |
| 还没有账户？注册       |
+------------------------+
```

**字段与操作**：

- 邮箱：必填，失焦后验证格式。
- 密码：必填，可显示/隐藏。
- 登录：字段合法后可点击；提交中按钮显示处理中并禁止重复提交。
- 登录成功：进入 `APP-01`。
- 登录失败：在表单内显示原因，不清空邮箱；密码错误时清空密码。

**状态**：初始、字段错误、提交中、凭证错误、网络错误、成功跳转。

**验收**：键盘可完成输入和提交；手机键盘弹出时登录按钮仍可到达；错误不使用只有颜色的提示。

## AUTH-02 注册

**目标**：通过邮箱和密码开放注册，不使用邀请码、手机号或微信登录。

**入口**：`AUTH-01` 的“注册”。

**桌面原型**：

```text
+----------------------------------------------------------------+
| 老己                                                           |
|                                                                |
|                    创建账户                                    |
|              [邮箱........................]                    |
|              [密码.................... 眼]                    |
|              [确认密码................ 眼]                    |
|              密码至少 8 个字符                                 |
|              [       注册并进入       ]                        |
|              已有账户？[登录]                                  |
+----------------------------------------------------------------+
```

**手机原型**：

```text
+------------------------+
| 老己                   |
|                        |
| 创建账户               |
| [邮箱................] |
| [密码............ 眼] |
| [确认密码........ 眼] |
| 密码至少 8 个字符      |
| [    注册并进入      ] |
| 已有账户？登录         |
+------------------------+
```

**规则**：

- 密码长度 8 至 64 个字符；确认密码必须一致。
- 注册提交中禁止重复操作。
- 注册成功后自动登录并进入 `APP-01`，不展示配置向导。
- 邮箱已注册时提供“去登录”和“忘记密码”。

**状态**：字段错误、邮箱已注册、注册中、网络错误、成功。

**出口与验收**：注册成功自动进入 `APP-01`；点击“登录”回到 `AUTH-01`。键盘可完成全表输入和提交，错误反馈不清空合法字段，页面不出现产品配置项。

## AUTH-03 忘记密码 / 重置结果

**目标**：用户通过邮箱恢复账户。

**入口**：`AUTH-01` 的“忘记密码”和重置邮件中的链接。

**桌面原型**：

```text
+----------------------------------------------------------------+
| 老己                                                           |
|                    重置密码                                    |
|              [邮箱........................]                    |
|              [       发送重置邮件       ]                      |
|              [返回登录]                                        |
|                                                                |
| 结果：如果账户存在，重置邮件已发送。 [重新发送]                 |
+----------------------------------------------------------------+
```

**手机原型**：

```text
+------------------------+
| < 返回登录             |
| 重置密码               |
| [邮箱................] |
| [  发送重置邮件      ] |
|                        |
| 如果账户存在，重置邮件 |
| 已发送。  [重新发送]   |
+------------------------+
```

- 结果文案不泄露邮箱是否已注册。
- 提供返回登录和重新发送入口。
- 重置成功后返回登录页，不自动展示其他配置。

**状态**：输入邮箱、字段错误、发送中、发送结果、网络错误、链接失效、重置中、重置成功。

**出口与验收**：发送结果页可返回 `AUTH-01` 或重新发送；重置链接失效时可重新申请。任何结果都不显示“邮箱不存在”，提交中禁止重复发送。

## APP-01 对话首页

**目标**：作为老己的默认入口，承载普通对话，并将读书/PPT 请求引导到对应工作区。

**桌面原型**：

```text
+------------+--------------------------------------+----------------+
| 老己       | 对话                         AI 未配置 | 当前上下文     |
|            +--------------------------------------+                |
| > 对话     | 老己：今天想整理哪本书？             | 最近阅读       |
|   读书     |                                      | 原子习惯 42%   |
|   设置     | 用户：帮我把最近的笔记做成 PPT       | 深度工作 18%   |
|            |                                      |                |
|            | [选择书籍并生成 PPT]                 | 最近笔记       |
|            |                                      | 5 条           |
|            +--------------------------------------+                |
|            | 输入消息...                    [发送] |                |
+------------+--------------------------------------+----------------+
```

**手机原型**：

```text
+------------------------+
| 老己         AI 未配置 |
+------------------------+
| 对话内容               |
|                        |
| [选择书籍并生成 PPT]   |
|                        |
+------------------------+
| 输入消息...       [>]  |
+------------------------+
| 对话 | 读书 | 设置    |
+------------------------+
```

**信息与操作**：

- 顶部 AI 状态为轻量文字/图标，不使用大面积配置卡。
- 有历史的空对话显示最近阅读、最近任务和可执行命令，不展示营销文案。
- 首次进入且没有对话、书籍、笔记或最近活动时，显示简短起步说明，主动作是“打开书架”，次动作是“导入书籍”；不出现 AI 或微信读书配置卡。
- “查看书架”进入 `BOOK-01`。
- “生成读书 PPT”要求选择一本书，随后进入 `PPT-01`。
- 用户触发“生成读书 PPT”但书架为空时，进入 `BOOK-01` 的真实空书架状态并保留创建 PPT 的意图；添加第一本书成功后显示“继续制作 PPT”，由用户确认后进入该书的 `PPT-01`。
- 带书籍上下文的对话在右侧显示当前书籍；手机端通过顶部按钮打开上下文抽屉。
- AI 未配置时允许输入；点击发送后就地提示“配置 AI 后可使用对话”，提供“去配置”和“取消”。
- 配置成功、失败后取消或主动取消返回时，都保留未发送文字和当前书籍上下文；只有验证成功后 AI 操作才可继续。
- 最近任务显示生成中、失败和已完成的 PPT；点击后回到对应书籍和作品状态，保证离开长任务页面后仍能找回任务。

**状态**：首次无任何数据、无对话但有最近内容、普通对话、回复生成中、回复失败、AI 未配置、Key 失效、书籍上下文、网络慢。

**验收**：对话只调度读书和 PPT；其他未来技能不展示空入口；重复发送被阻止；失败消息可重试。

## BOOK-01 统一书架

**目标**：在一个入口查看、搜索和管理微信读书同步书及本地导入书。

**桌面原型**：

```text
+------------+-------------------------------------------------------+
| 老己       | 读书        AI 未配置·去配置        [同步] [导入]|
|            +-------------------------------------------------------+
|   对话     | [搜索书名或作者...] [全部|微信读书|我的导入] [最近访问v]|
| > 读书     +-------------------------------------------------------+
|   设置     | [封面]     [封面]     [封面]     [封面]               |
|            | 原子习惯   深度工作   被讨厌的勇气  思考，快与慢       |
|            | 微信读书   我的导入   微信读书      我的导入           |
|            | 进度 42%   进度 18%   12 条划线    PDF                |
+------------+-------------------------------------------------------+
```

**手机原型**：

```text
+----------------------------+
| 读书             [同步][+] |

+----------------------------+
```

**书籍卡片**：

- 必须展示封面、书名、作者和来源；书架卡片中的来源是低层级辅助文字，不使用高强调实色标签。
- 微信读书显示同步进度或笔记数量；本地导入显示文件类型和本地进度。
- 同名不同来源显示为两张卡片，不自动合并。
- 封面缺失或源图清晰度不足时使用稳定比例的文字封面；任何来源图片都不拉伸或超出清晰度上限放大。
- 长书名最多两行，作者一行；溢出截断，不改变卡片高度。

**搜索与筛选**：

- 搜索匹配书名或作者，输入后更新当前书架结果。
- 来源筛选为分段控件：全部、微信读书、我的导入。
- 默认排序为最近访问；可切换最近更新、书名。
- 搜索和筛选可叠加；清空搜索保留来源筛选。

**主要操作**：

- 同步：未连接进入 `SET-02`；已连接开始同步并在当前页显示状态。
- 导入：打开文件选择，限制 EPUB/PDF；选择后显示上传/解析进度。
- 点击微信读书卡片进入 `BOOK-02`。
- 点击 EPUB 卡片进入 `BOOK-03`；点击 PDF 卡片进入 `BOOK-04`。
- 本地书卡片菜单提供“移除”；微信读书卡片不提供单书移除。

**状态**：初次加载、首次空书架、已连接但同步结果为空、当前来源筛选为空、仅微信读书、仅本地书、同步中、部分同步失败、导入中、导入失败、搜索无结果、加载更多、网络错误。

**缺省与失败状态**：

| 状态 | 界面说明 | 主要动作 | 次要动作 |
| --- | --- | --- | --- |
| 初次加载 | 使用稳定骨架，不显示“书架为空” | 等待 | 无 |
| 首次空书架且未连接 | 说明可以同步微信读书或导入本地书 | 导入书籍 | 连接微信读书 |
| 已连接但同步结果为空 | 说明当前账号尚未同步到书籍，不误报失败 | 重新同步 | 导入书籍 |
| 当前来源筛选为空 | 说明当前来源没有书，但保留其他来源数量 | 查看全部 | 添加当前来源书籍 |
| 搜索无结果 | 显示当前搜索词，不发起外部搜索 | 清除搜索 | 调整来源筛选 |
| 网络错误且无缓存 | 说明书架暂时无法加载，不显示空书架文案 | 重试 | 无 |
| 网络错误但有缓存 | 保留已有书籍并显示非阻塞错误 | 重试 | 继续浏览 |

这些空状态只在用户进入书架后出现，不在注册成功后的对话首页提前展示连接卡。

- 供应商选项：DeepSeek、Kimi、GLM。
- 不展示具体模型选择。
- 验证成功后显示可用能力状态；未验证能力不显示为可用。
- 替换 Key 先验证新 Key，成功后才替换旧配置。
- 撤销配置需确认；撤销后阅读和笔记仍可用，AI 操作恢复未配置提示。
- 从某个 AI 操作进入设置时，成功后返回原上下文。
- 验证失败后用户可以继续修改并重试，或取消返回原页面；取消不丢失原操作上下文。

## SET-02 微信读书连接设置

**目标**：配置、验证和撤销微信读书 Skill Key。

```text
+------------------------------------------+
| 微信读书                                |
| 状态：未连接 / 验证中 / 已连接 / 已失效  |
|                                          |
| Skill Key [**********************] [眼]   |
| [验证并连接]                             |
|                                          |
| 最近同步：2026-08-03 14:20               |
| [立即同步] [修改 Key] [清除凭证]          |
+------------------------------------------+
```

**规则**：

- 不提供二维码或微信登录按钮。
- 验证失败保留输入并说明可操作原因，不展示第三方原始错误码。
- 清除凭证需确认；停止后续同步，已同步内容保留只读。
- 微信读书单书在 MVP 不提供移除；账户删除时统一删除用户数据。

## SET-03 账户与回收站

**目标**：管理邮箱、密码、登录状态、本地书回收站和账户删除。

**结构**：

```text
账户
+-- 邮箱
+-- 修改密码
+-- 退出登录
+-- 删除账户

回收站
+-- 本地书名称 / 删除日期 / 剩余天数
    +-- 恢复
    +-- 永久删除
```

**规则**：

- 本地书移除后保留 30 天，包含文件、划线和本地笔记。
- 恢复后回到统一书架并恢复相关笔记。
- 永久删除需二次确认；已生成 PPT 保留。
- 删除账户是独立高风险操作，需密码确认并说明会删除账户数据和作品。

**回收站状态**：加载中、有内容、空、加载失败、恢复中、恢复失败、永久删除确认。

- 空回收站显示“回收站为空”和“移除的本地书会在这里保留 30 天”，不强行提供主操作。
- 加载失败显示“暂时无法加载回收站”和“重试”，不得显示为空。

| 对象 | 状态 | 界面行为 | 用户可执行动作 |

### 重复操作规则

- 所有提交型按钮在处理中禁用，并保持固定尺寸。
- 重试复用原任务和用户输入，不创建不可区分的重复记录。
- 用户离开长任务页面后，任务继续显示在对应书籍的状态区域，并同步出现在 `APP-01` 最近任务中；任务完成、失败或被删除后两处状态保持一致。

## 7. 响应式规则

### 7.1 布局区间

- 桌面：宽度 1200px 及以上，固定侧栏，可使用多栏工作区。
- 平板：宽度 768px 至 1199px，侧栏收窄，目录/笔记可折叠。
- 手机：宽度 767px 及以下，底部导航，正文和当前任务占主视区。

### 7.2 共同行为

- 手机端不依赖悬停；图标按钮有可见标签或辅助说明。
- 触控目标不小于 44px，操作条和工具栏尺寸稳定。
- 书架桌面端采用紧凑封面网格，在常见桌面视口内优先展示至少两行书籍，不能因封面无限放大而只剩一行。
- 书架手机端默认双列；极窄屏按内容宽度自适应，不能挤压书名。
- 阅读器目录和笔记在手机端使用抽屉或底部面板，不与正文并排。
- PPT 大纲手机端逐页编辑，不将三栏桌面布局整体缩小。
- 长书名最多两行；长作者名一行；不可覆盖来源标签和进度。
- 键盘弹出时，当前输入和主要提交按钮可滚动到可见区域。
- 弹窗、抽屉和底部面板一次只保留一个主要层级，避免嵌套。

## 9. UI 设计输入

### 9.1 视觉方向

- 已接受方向为“青瓷书斋”：清新、安静、有书卷气，以现代工作台为骨架，以克制的国风细节建立识别。
- 国风元素使用“己”字题签、活字印刷字模暗纹、青瓷色和阅读排版；不使用大面积水墨、仿古纸纹或无功能含义的装饰性分组标题。
- 书架以封面为第一识别信号，文本信息用于辅助区分来源和进度。
- 书架来源信息需要可识别但弱化，不使用醒目的填充标签；进入书籍详情、笔记和 PPT 来源查看时再提高来源可见性。
- 桌面端所有已登录主页面在页头提供 AI 配置弱提示，显示未配置、当前供应商或凭证失效状态；点击进入 `SET-01` 并保留当前上下文。
- 阅读区优先保证文本宽度、行距和选区清晰度。
- AI 状态和配置提示保持轻量，不做大卡片或强制向导。
- 卡片仅用于书籍、笔记、作品等重复实体；页面区块不包装成多层卡片。

上述方向的色值、字体、封面尺寸、网格密度和组件状态以 `../ui/laoji-mvp-ui-design-spec.md` 为唯一事实源，本文不复制具体参数。

### 9.2 UI 需输出的页面状态

UI 设计稿至少覆盖：

- 15 个页面的桌面主状态和手机主状态；
- 统一书架的空、正常、搜索无结果、同步中；
- 微信读书未连接、连接失效；
- AI 未配置和配置失败；
- EPUB 正文选区；
- PDF 跨页选区和不支持精准划线；
- 笔记编辑和公开参考选中；
- PPT 素材、大纲、生成中、失败和完成；
- 回收站和破坏性操作确认。
- 首次无任何数据、来源筛选为空、同步结果为空、无个人内容、无公开参考、无笔记、无 PPT 素材、无 PPT 作品和空回收站。

### 9.3 设计参考边界

微信读书和 Alice APP 只作为交互习惯和信息层级参考。此前提供的临时截图现已不可读取；高保真设计需要精确比对时需重新提供，不影响本原型 PRD 的页面和行为定义。

## 12. 原型冻结规则

- UI 可以调整视觉层级、排版和组件表现，但不能改变页面职责、来源能力和已接受流程。
- UI 发现内容溢出或移动端不可用时，优先调整布局，不删除产品状态。
- 开发发现技术不可行时，先回到对应阶段 0 验证结论，不在实现中静默降级产品承诺。
- 新增功能必须先判断是否属于 MVP；不在范围内的内容进入后续版本清单，不直接塞进当前页面。
