# ADR-0002: 大模型 API Key 不是注册和阅读的前置条件

- 状态：已接受
- 日期：2026-07-31；2026-08-09 同步 AI 状态入口的设计自由度
- 范围：注册后引导、阅读工作台、AI 功能权限

## 背景

老己的第一版以读书工作台为核心。用户可能希望先体验导入、阅读、划线和笔记，再决定是否配置自己的大模型 API Key。如果把 Key 配置作为注册门槛，会阻断核心阅读体验。

## 决策

用户可以在注册后跳过大模型 API Key 配置。未配置 Key 时，以下功能仍然可用：

- 阅读微信读书同步内容；
- 导入 EPUB 和文字型 PDF；
- 精准划线；
- 添加个人备注、标签和 PPT 备注；
- 查看同步的公开划线、公开想法和公开书评。

以下功能需要配置并验证可用的 AI Key：

- 对话式读书问答和智能整理；
- 自动总结、状态分析等 AI 能力；
- PPT 大纲生成；
- PPT 配图与 PPTX 生成流程中的 AI 内容生成。

## 用户体验

注册和登录完成后直接进入产品，不展示大面积 AI 配置卡。已登录主要页面提供轻量、可发现的 `AI 未配置` 状态；用户第一次执行需要 AI 的操作时，再在当前上下文中显示配置提示，并保留用户当前阅读或对话上下文。状态入口的具体位置由 UI 设计决定。

## 后果

- 阅读功能必须与 AI 服务解耦，不能在加载书籍或保存划线时强制调用大模型。
- AI 操作需要有明确的未配置状态和可恢复的配置入口。
- 产品可以在没有 AI Key 的情况下获得真实的阅读与笔记使用反馈。
