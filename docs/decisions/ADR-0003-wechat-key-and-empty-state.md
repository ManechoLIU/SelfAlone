# ADR-0003: 微信读书凭证与 AI 凭证分开配置，并提供未配置状态

- 状态：已接受
- 日期：2026-07-31；2026-08-09 同步 AI 状态入口的设计自由度
- 范围：首次进入、设置、读书入口、微信读书同步

## 背景

老己同时依赖两类外部服务：

1. AI 供应商，用于对话、读书整理和 PPT 生成；
2. 微信读书 Skill/API，用于同步书架、阅读进度、我的笔记和书友笔记。

两者的凭证属于不同系统，不能合并成一个配置项。此前的信息架构图只画出了设置入口，没有明确首次进入时微信读书 Skill Key 的填写位置，也没有画出两个 Key 都为空时的产品状态。

## 决策

1. 注册和登录完成后，不同时展示 AI 配置卡和微信读书连接卡，不用配置向导阻塞用户进入产品。
2. 设置首页的“已连接的服务”区提供两个独立的管理入口：
   - `AI 服务`：供应商选择 + 一把 AI API Key；
   - `微信读书`：微信读书 Skill Key。
3. 注册和登录不要求填写任意 Key，完成后直接进入产品首页。
4. AI 未配置时，只在可发现的全局状态入口或当前 AI 操作处显示轻量提示，例如 `AI 未配置` 和 `去设置`；不在首页展示大面积配置卡，具体位置由 UI 设计决定。
5. 用户第一次执行需要 AI 的操作时，使用就地提示引导配置，并保留用户原本的书籍或对话上下文。
6. 微信读书不在注册后主动弹出连接卡。用户进入设置首页的 `微信读书 -> 管理`、`读书 -> 微信读书同步` 或点击同步时，进入同一个 `SET-02` 配置页。
7. 未连接微信读书时，用户仍可使用“我的导入”，但“微信读书同步”页展示连接引导，不显示为空白书架或误报连接失败。
8. 未配置 AI 时，用户仍可阅读、划线和记笔记；AI 操作入口显示配置提示。

## 默认状态示意

```text
+----------------------------------------------------------+
| 老己                         AI：未配置   [头像 / 设置] |
+----------------------------------------------------------+
|                                                          |
|                    对话首页 / 最近内容                  |
|                                                          |
|  需要 AI 的操作在用户真正点击时，再显示 [去配置 AI]      |
|                                                          |
+----------------------------------------------------------+
```

进入微信读书同步入口时：

```text
+--------------------------------------------------+
| 微信读书同步                                     |
|                                                  |
| 尚未连接微信读书                                 |
| 连接后可同步书架、进度、我的笔记和书友笔记       |
|                                                  |
|                 [填写 Skill Key]                 |
+--------------------------------------------------+
| 我的导入：EPUB / 文字型 PDF       [导入书籍]      |
+--------------------------------------------------+
```

微信读书连接失败时保留 `重试` 和 `修改 Skill Key` 入口；设置中允许清除微信读书 Key 并停止后续同步。

配置页使用“API Key + 保存 + 测试”的紧凑服务卡：保存只持久化当前 Key，不开始同步；测试成功后才标记为已连接并启用同步。已保存但未测试成功显示已配置，测试失败保留掩码输入和重试入口。

重新同步按微信读书外部稳定标识更新已有内容，不重复创建；外部内容不再返回时保留本地快照并标记来源失效，不删除用户创建的老己笔记。更换 Skill Key 后，新账号数据不与旧账号自动合并，旧账号已同步内容继续保留为只读。
