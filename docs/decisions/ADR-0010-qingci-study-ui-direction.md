# ADR-0010: MVP 采用“青瓷书斋”UI 方向

- 状态：已接受
- 日期：2026-08-04；2026-08-08 同步书架来源层级；2026-08-09 同步设计自由度边界
- 范围：品牌视觉、全局导航、统一书架、AI 状态入口、响应式体验与设计自由度

## 背景

老己需要同时承载长时间阅读、知识整理和 PPT 生产。过于通用的企业后台缺少产品识别，过度仿古的国风界面又会降低操作效率、文字清晰度和跨端一致性。

书架早期深化稿还暴露了三个具体问题：国风特征偏弱；来源标签抢夺书名和封面的注意力；封面过大导致桌面首屏书籍数量过少，并可能放大低清微信读书封面。桌面端也需要在设置之外持续显示 AI 配置状态，但不能用配置卡阻塞用户。

## 决策

1. MVP 采用“青瓷书斋”方向：现代工作台为骨架，青瓷色、题签、活字印刷暗纹和阅读排版作为克制的国风识别。
2. “己”字题签是主要品牌记忆点；国风装饰不得伪装成功能分组或增加无意义文案。
3. 统一书架不使用任何来源图形、角标或文字标签，封面、书名、作者和必要进度构成完整卡片层级。来源筛选器承担筛选职责；书籍详情、笔记和 PPT 引用场景必须以清晰元信息追溯来源。
4. 所有已登录主页面提供可发现但不抢占主任务的 AI 状态弱提示，至少覆盖未配置、已启用供应商和凭证失效；点击进入 AI 设置并保留原上下文。具体位置和组件形态由 UI 设计决定。
5. 书架优先保证快速扫描、封面清晰和书名可识别；列数、卡片尺寸和间距由 Open Design 根据视口与真实内容验证。低清或缺失封面不拉伸，使用文字封面兜底。
6. 具体色值、字体、尺寸、断点和组件表现只在 `../ui/laoji-mvp-ui-design-spec.md` 中维护，不在 ADR 中复制。
7. PRD 约束能力、内容、流程、状态、文案和验收结果；导航承载、区块位置、分栏方式、抽屉/面板方向及具体响应式布局由 Open Design 决定。PRD 中的 ASCII 示意只用于核对信息与流程，不作为高保真布局要求。

## 后果

### 正面

- 形成与中文阅读和“老己”名称相关的视觉识别，同时保持工具效率。
- 来源、AI 状态和书架密度拥有明确层级，不会互相争夺注意力。
- 低清第三方封面有稳定兜底，不需要通过放大像素素材填满网格。

### 代价与约束

- 国风细节需要严格克制，新增装饰前必须说明其结构或品牌作用。
- 微信读书实际封面尺寸仍需在阶段 0 用真实接口数据验证；若无法取得足够清晰的图片，必须接受文字封面比例上升。
- UI 评审需要同时检查不同桌面与移动视口、长书名和低清封面，不能只评审单一理想尺寸或单个书籍卡片。
- Open Design 获得布局与组件自主权后，评审必须依据产品任务完成度、可发现性、可访问性和状态恢复，而不是依据是否复刻 PRD 示意图。
