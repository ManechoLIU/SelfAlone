# 老己 MVP 品牌规格摘录

本文件从 `laoji-mvp-ui-design-spec.md` 提取，作为后续响应式网页设计的视觉绑定；产品行为仍以 `laoji-mvp-prototype-prd.md` 为准。

## 核心 Tokens

```css
:root {
  --bg: oklch(0.9763 0.0041 157.18);
  --surface: oklch(0.9610 0.0084 168.75);
  --fg: oklch(0.2975 0.0225 177.49);
  --muted: oklch(0.5857 0.0198 169.62);
  --border: oklch(0.8709 0.0156 170.99);
  --accent: oklch(0.4696 0.0856 174.05);
}
```

色值对应原规范中的瓷白 `#F5F8F6`、雾釉 `#EDF4F1`、墨青 `#21312D`、竹影灰 `#71807A`、釉边 `#CBD8D3` 与青瓷 `#0D6A57`。警告与危险状态继续引用原规范中的淡赭与朱砂角色，不擅自改色。

## 字体栈

- Display / 品牌：`Kaiti SC`, `STKaiti`, serif；只用于“老己”和低频“己”字题签。
- Body / UI：`Source Han Sans SC`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
- Reading / 引用：`Source Han Serif SC`, `Songti SC`, `STSong`, serif。
- Mono / 数据辅助：`Inter`, system-ui, sans-serif；只用于页码、进度、文件类型与英文辅助信息。

## 视觉语言规则

1. 以现代知识工作台为骨架，正文和当前任务优先，东方气质退居细节层。
2. 品牌记忆点只使用竖向“己”字题签与不超过 4% 不透明度的活字字模暗纹。
3. 卡片只承载书籍、笔记、PPT 作品等重复实体；页面结构依靠留白与细线，不做多层套卡。
4. 来源在书架中弱化，在老己笔记、书友笔记和 PPT 引用中强化，并始终用文字辅助辨认。
5. 一个操作组只保留一个青瓷实色主动作；国风表达不得影响效率、对比度或长时间阅读。

## 一句话系统说明

“青瓷书斋”用瓷白背景、墨青正文、青瓷交互色与克制的题签细节，建立安静、可信赖、适合长期阅读与知识整理的现代工作台。
