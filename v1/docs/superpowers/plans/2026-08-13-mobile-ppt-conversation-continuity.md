# 移动端 PPT 对话连续性实施计划

## 目标

落实 `2026-08-13-mobile-ppt-conversation-continuity-design.md`：统一移动对话底部布局，补齐选书、范围、大纲、模板与生成之间的连续阶段卡和返回恢复行为，同时保持桌面右侧工作台不退化。

## 实施步骤

1. 在移动 PPT 工作台契约测试中增加以下失败断言：统一静态输入器行、无 `bottom` 二次偏移、四个阶段页存在独立阶段卡、选书后动态创建范围卡、作品层返回恢复触发焦点。
2. 调整 `laoji-chat.html`、`laoji-ppt-materials.html`、`laoji-ppt-outline.html` 和 `laoji-ppt-preview.html` 的消息时间线：任务卡与助手气泡分离，书籍身份压缩为低强调上下文，页面之间承接上一阶段结果。
3. 在共享 CSS 中增加阶段卡样式；在最后一层移动覆盖中把所有对话输入器改为静态网格行并清除 `bottom`，只由页面骨架扣除一次底部导航和安全区。
4. 在共享 JS 中提取或新增阶段卡创建逻辑；选书确认后追加范围卡并打开作品层；记录进入作品层的触发控件，返回时恢复滚动、草稿与焦点。
5. 做事实源影响扫描。PRD 和 UI 主规范已有同义规则时不重复改写，仅保持专项规格、原型和测试一致。
6. 运行目标测试、相关 PPT 生命周期和移动会话回归、全量原型测试及 `git diff --check`；通过浏览器检查 360、390、430、768、1024、1200、1440px，以及 200% 文本缩放相关结构。

## 修改边界

- 只修改四个对话/PPT 页面、共享 `laoji.css`、共享 `laoji.js`、相关测试和本专项计划。
- 不改设置、阅读器、书架、全局设计令牌或已完成的 PPT 预览生命周期布局。
- 保留工作区中所有现有用户改动。

## 完成条件

- 三种移动对话状态的输入器到一级导航距离一致。
- 每个 PPT 阶段有且只有一个当前任务入口，返回作品层后可继续。
- 移动作品层隐藏输入器与一级导航，返回恢复消息位置、草稿和焦点。
- 桌面双区布局、PPT 生命周期和相关回归测试全部通过。
