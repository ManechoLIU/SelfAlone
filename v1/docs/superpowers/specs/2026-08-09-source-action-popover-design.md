# 原文操作浮层设计说明

## 目标

把微信读书详情页中原本占据卡片空间的操作按钮，改为贴近当前内容的悬浮工具条。工具条不改变卡片高度，不打断阅读，并与参考图保持相同的交互心智。

## 交互决策

- 微信读书同步卡片：桌面端鼠标悬浮或键盘聚焦时出现；手机端点按可操作内容后出现，焦点移出后隐藏。
- EPUB/PDF 原文：仅在用户真实选中文本后出现，浮层定位到选区上方；取消选区、滚动页面或完成操作后隐藏。
- 工具条悬浮在内容上方中央，使用深色背景、分段文字按钮与向下指示箭头。
- 每个按钮保持至少 44px 高度，并提供清晰的悬浮、按下和键盘焦点状态。
- 微信读书同步内容是只读来源：已有划线与热门划线只提供“复制、写笔记”。“划线”只属于原文选区工具，不在已保存内容上重复出现。
- 不增加“聊一聊”，因为当前原型没有相应的内容级会话能力。

## 视觉边界

- 沿用现有青瓷色设计令牌，不新增页面级颜色或全局组件。
- 深色工具条使用现有前景色，按钮使用白色文字；分隔线与悬浮态均从现有颜色派生。
- 本次只更新微信读书详情页中的卡片操作，以及 EPUB/PDF 阅读区的原文选区操作；不改动书籍详情结构、标签页或阅读器工作区布局。

## 验收标准

1. 操作工具条不再占据卡片正文布局空间。
2. 鼠标、键盘和触屏均能唤起并操作工具条。
3. 热门划线工具条只显示“复制、写笔记”。
4. 工具条具备指向内容的箭头、分隔线与可见焦点状态。
5. EPUB/PDF 未选中文本时不显示工具条；选中后显示“复制、划线、写笔记”。
