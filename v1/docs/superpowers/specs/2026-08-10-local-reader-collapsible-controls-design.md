# 本地书籍折叠操作栏设计

## 状态

- 日期：2026-08-10
- 状态：已确认，待实施
- 范围：`prototype/laoji-epub-reader.html`、`prototype/laoji-pdf-reader.html` 及对应回归测试。

## 背景

EPUB 与 PDF 都属于本地导入书籍，但当前普通阅读态的操作栏布局、宽度和显隐方式仍不一致。桌面端操作栏常驻在正文顶部，占用阅读空间，并以大面积浅色背景形成过强视觉块；移动端已经采用点击阅读区域后按需唤起的方式。

## 目标

- EPUB 与 PDF 使用一致的阅读器骨架、操作栏视觉和显隐规则。
- 桌面端与移动端都默认收起操作栏，点击正文后才显示。
- 操作栏参考微信读书的克制方式：轻边框、窄胶囊、低对比背景，不形成横跨正文的大色块。
- 两种书籍统一使用“缩小、标准、放大”的用户操作；EPUB 调整字号、PDF 调整页面缩放只属于内部实现，不在界面中区分。
- 两种书籍都显示统一的阅读进度，不在操作栏中暴露 PDF 页码、适合宽度等格式专属概念。
- 不破坏目录、划线想法、阅读进度和专注模式等既有能力。

## 交互设计

### 普通阅读态

- 页面进入时操作栏不可见，不为其预留垂直空间。
- 点击或轻触正文空白区域时显示操作栏；再次点击正文可收起。
- 显示后 3 秒无操作自动收起。
- 正文滚动时立即收起，减少遮挡。
- 选中文字、点击划线、操作目录或操作栏内部控件时，不切换操作栏显隐。
- 键盘用户将焦点移入操作栏时保持显示；焦点离开后恢复自动收起。

### 专注阅读态

- 继续使用现有全屏与回退全屏机制。
- 点击正文唤起顶部退出按钮和底部操作栏，3 秒后自动收起。
- 目录仍为临时抽屉；打开目录时控制层保持可见，关闭目录后恢复计时。

## 响应式规则

### 桌面端

- 操作栏固定在阅读工作区底部中央，不占据正文正常布局。
- 最大宽度由内容决定，不横跨正文。
- 与浏览器底部保留安全距离，避免遮挡当前阅读行。

### 移动端

- 操作栏位于底部导航上方，并计入安全区。
- 控件触控区域不小于 44px。
- 文字标签在空间不足时隐藏，但保留可访问名称。

## 视觉设计

- 容器采用接近纸张色的半透明背景、1px 低对比边框和轻微阴影。
- 圆角使用紧凑胶囊形态，但不使用大面积填充色。
- 控件默认透明，仅悬停、聚焦或按下时出现很浅的青瓷反馈。
- 组内不再额外套大色块；用细分隔线或间距表达分组。
- 阅读进度和当前显示级别使用弱化的数据文字，不伪装成按钮。

## 统一控件结构

| 位置 | 两种本地书籍的统一界面 |
| --- | --- |
| 左侧 | 目录 |
| 中部主控 | 缩小、当前显示级别、放大 |
| 状态 | 阅读进度百分比 |
| 右侧 | 专注阅读 |

用户只控制阅读内容在视觉上的大小，不需要理解文件格式或底层渲染方式。EPUB 可以通过字号完成，PDF 可以通过页面缩放完成，但按钮名称、顺序、状态表达和结果反馈必须一致。

## 状态与可访问性

- 工作区使用统一的 `local-reader-controls-visible` 状态控制普通阅读操作栏。
- `aria-hidden` 与实际显隐同步；隐藏时禁止指针交互。
- 专注按钮继续维护 `aria-pressed` 和动态标签。
- 尊重 `prefers-reduced-motion`，关闭位移过渡，仅保留即时显隐。

## 验收标准

- EPUB 与 PDF 初始加载时操作栏均不可见且不占布局高度。
- 两页点击正文均可唤起，3 秒后均自动隐藏，滚动均立即隐藏。
- 两页选择文字、点击划线和操作栏内部点击不会误切换显隐。
- 桌面与移动操作栏均为紧凑浮层，无横跨正文的大面积浅色块。
- 两页都使用相同的“缩小、标准、放大、阅读进度、专注阅读”结构，不显示格式专属控件或文案。
- 放大和缩小在两页都应产生一致的用户结果：正文阅读内容明显变大或变小。
- 现有目录、划线想法、专注模式和完整原型测试保持通过。
