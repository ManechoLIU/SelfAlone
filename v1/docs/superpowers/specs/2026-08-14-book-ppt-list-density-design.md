# 书籍“读书 PPT”列表与材料确认区精简设计

## 背景

当前书籍“读书 PPT”列表沿用通用实体卡片，重复显示状态、时间、页数、说明和下载按钮，手机显得冗长，桌面也没有利用可用宽度。材料确认区同时重复展示书籍身份、阶段、静态保存提示和帮助文案，使唯一主操作不够集中。

本设计以 `image-39.png` 的移动端作品列表和 `output/imagegen/ppt-workbench-unified-shell-reference-v1.png` 的桌面工作台为视觉参考。参考图只决定信息层级、密度和作品感；现有青瓷书斋颜色、字体、数据状态和流程规则保持不变。

## 目标

- 让生成任务和完成作品可以通过真实 16:9 缩略图、状态和标题快速识别。
- 删除重复解释与列表内低频操作，让每条记录只有一个明确进入动作。
- 手机和桌面统一使用单列横向作品条目，保持同一信息顺序和视觉结构。
- 精简材料确认区，但不改变范围、用途、分享对象、页数和生成大纲的状态逻辑。

## 非目标

- 不修改大纲、模板、生成瀑布流或作品详情页布局。
- 不改变 PPT 任务与作品的数据模型、排序、恢复和删除语义。
- 不重做书籍详情页头、标签栏、阅读器或全局导航。
- 不新增下载、分享、版本管理或批量管理能力。

## 1. 书籍“读书 PPT”作品索引

### 1.1 共同结构

每条记录由真实模板缩略图和三行以内的文字组成：

1. 状态或时间元信息；
2. 作品标题；
3. 仅在生成中、正在完成文件或失败时显示的必要恢复信息。

完成作品不再显示“完成作品”“点击查看瀑布流预览”“独立作品 · 不覆盖”等解释。页数与创建时间合并为一行。完成作品不在列表内显示“下载 PPTX”；用户进入作品后下载。

整张记录提供进入作品的链接语义和清晰键盘焦点。缩略图保持装饰性，链接的可访问名称由状态、标题和页数共同组成。

### 1.2 生命周期文案

- 生成中：`正在生成第 N / 总页数页`、标题、`可离开，后台继续`。
- 正在完成文件：`正在完成文件`、标题、`已完成 N / 总页数页`。
- 完成：`创建时间 · 总页数页`、标题，不显示第三行。
- 失败：`生成失败 · 已完成 N / 总页数页`、标题，并保留一个主操作 `继续`。删除任务保留为低频文字操作，不与主操作并列成两个实心按钮。

### 1.3 响应式

- `<=767px`：单列横向条目，缩略图固定在左侧，文字在右侧；条目触控区域不小于 44px，不产生横向滚动。
- `>=768px`：继续保持单列横向条目，只增加可用文字宽度，不切换为双列，也不放大缩略图到抢占内容层级。
- 加载态与真实作品使用同一横向网格，只显示缩略图和三条骨架；不显示“读取生成任务与作品”等实现解释。
- 加载、真实空、失败和正常列表继续由现有状态容器切换，不让加载或失败闪现为空状态。

## 2. 材料确认区

### 2.1 信息减法

- 作品区页头保留 `确认 PPT 范围`，移除重复的 `原子习惯 · 读书 PPT` 眉题和静态 `草稿已保存`。
- 保留内容范围、用途、分享对象和页数四组字段及现有选项值。
- 内容范围选项移除重复解释，只显示 `整本书 / 指定章节 / 已有老己笔记`。
- 页数选项合并为 `精简 · 5 页 / 标准 · 8 页 / 详细 · 12 页`。
- 移除“补充要求可继续在左侧对话中发送”，左侧输入器本身已表达该能力。

### 2.2 操作

- 唯一实心主操作的可见文案改为 `生成大纲`。
- 按钮保留 `aria-label="确认范围并生成大纲"`，继续使用表单提交、草稿保存、防重复提交和带会话身份的跳转。
- 工作台开合按钮的可见文案缩为 `收起`，可访问名称仍为 `收起作品工作台`。

## 3. 实现边界

- `prototype/assets/laoji.js`：调整共享书籍 PPT 列表记录的语义结构和文案，不改记录查询与状态源。
- `prototype/assets/laoji.css`：只修改 `.book-ppt-list` 与 `.ppt-record-*` 相关规则，复用现有视觉变量。
- `prototype/laoji-ppt-materials.html`：只修改材料工作台页头、选项文案、提示与主操作文案。
- `prototype/tests/`：新增或更新结构、文案、响应式和交互回归断言。
- `docs/prd/laoji-mvp-prototype-prd.md` 与 `docs/ui/laoji-mvp-ui-design-spec.md`：同步当前有效的列表动作与可见文案，不记录变更历史。

## 4. 验收

- 微信读书、EPUB 和 PDF 三种书籍详情均由共享渲染器获得相同作品索引。
- 手机 360、390、430px 无横向滚动，卡片不截断，整卡可点击且焦点可见。
- 768、1024、1200、1440px 始终保持单列，标题、状态和缩略图不重叠。
- 完成作品列表中没有 `下载 PPTX`、`完成作品` 或重复查看说明。
- 失败任务仍可继续和删除；生成中、正在完成文件、空状态和加载失败语义不变。
- 材料页只剩一个实心主操作 `生成大纲`，点击仍保存草稿并进入当前会话的大纲页。
- 目标测试、相关全量原型测试、链接检查与 `git diff --check` 通过。
