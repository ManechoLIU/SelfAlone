# 老己共享导航图标与品牌尺寸锁定设计规范

状态：已确认（方案 A）  
日期：2026-08-11  
参考：`open-design-ui-reference/laoji-chat-desktop-mobile.png`、`open-design-ui-reference/laoji-navigation-icon-comparison.html`

## 1. 目标

为对话、读书、设置及其子页面补齐一套共享主导航图标，并消除模块切换时 Logo、品牌字和侧栏宽度发生缩放或位移的问题。只调整共享导航的视觉资产与尺寸，不改变导航路由、页面内容或业务交互。

## 2. 已确认方向

采用对比稿 A“严格贴近 Image2”：

- 对话：方圆角气泡，内部两枚圆点。
- 读书：对称打开书本，中缝清晰。
- 设置：细线齿轮，中心留白。
- 三枚图标使用统一 `24 × 24` SVG 画布、`20px` 桌面显示尺寸和约 `1.75px` 的视觉线宽。
- 图标使用 `currentColor` 继承导航状态；选中态只改变前景色和浅青瓷背景，不缩放、不改变描边。
- 桌面侧栏与移动底栏复用同一组本地 SVG，不再使用 CSS 边框、圆角和伪元素拼图。

## 3. 本地资产

新增三个单色 SVG：

- `prototype/assets/icons/nav-chat.svg`
- `prototype/assets/icons/nav-library.svg`
- `prototype/assets/icons/nav-settings.svg`

SVG 只定义几何轮廓，不写死界面颜色。三个文件是图标几何的源资产；共享 CSS 内嵌与源文件逐字一致的 SVG data URI 作为 `mask-image`，并通过 `background-color: currentColor` 着色。这样直接刷新与站内切换不依赖预览环境先建立外部 SVG 资源作用域，也无需在各页面重复内联 SVG。

## 4. 品牌尺寸锁定

桌面端统一使用：

- 标准侧栏（≥1200px）：`188px`。
- 紧凑侧栏（768–1199px）：`168px`。
- 品牌头像／Logo：`38 × 38px`，固定 `flex-basis: 38px`。
- “老己”品牌字：`25px`，行高 `1`，字距 `.06em`。
- 品牌区最小高度：`62px`；左右内边距 `8px`，底部内边距 `24px`。
- 侧栏内边距：顶部 `26px`、左右 `14px`、底部 `22px`。
- 导航列表：顶部间距 `24px`、项目间距 `6px`。
- 导航项目：最小高度 `48px`、图文间距 `13px`、左右内边距 `13px`、圆角 `9px`。

移动端（≤767px）继续隐藏桌面侧栏，仅显示底部导航；品牌区尺寸不会进入移动布局。

不得在 `.chat-page`、`.library-page`、设置页或阅读/PPT 子页面重新定义上述尺寸。页面级样式只能控制自身内容，不能覆盖共享品牌锁定。

## 5. 导航状态

- 桌面图标显示为 `20 × 20px`，与文字保持 `13px` 间距。
- 移动底栏图标显示为 `19 × 19px`，文字保持现有 11px。
- 默认：`var(--muted-strong)`。
- 悬停：前景保持可读，背景使用现有 `--surface-strong`。
- 当前模块：前景使用 `var(--accent-hover)`，背景使用 `var(--accent-soft)`。
- `:focus-visible` 继续使用共享焦点环；任何状态都不得改变图标尺寸。

## 6. 覆盖范围

共享规则覆盖所有包含 `.side-nav` 或 `.bottom-nav` 的原型页面，包括：

- 对话及 PPT 子流程。
- 书架、微信读书详情、本地 EPUB/PDF 阅读器。
- 设置、AI 配置、微信读书连接。

登录、注册、找回密码使用独立认证品牌区，不纳入本次共享导航修改。

## 7. 验收标准

- 对话、读书、设置之间切换时，≥1200px 下侧栏恒为 188px，Logo 恒为 38px，“老己”恒为 25px；品牌和导航项目的上下位置不跳动。
- 768–1199px 下侧栏恒为 168px，但 Logo、品牌字和图标尺寸不变化。
- 三个桌面导航入口和三个移动底栏入口均显示对应图标。
- 当前项切换时只改变颜色和背景，不发生尺寸、线宽或位置跳动。
- 不再出现 `.nav-dot` 的边框圆点、底栏书本边框、齿轮圆环等 CSS 临时图形。
- 360、390、430、768、1024、1366px 均无导航溢出或文字截断。
- 既有原型测试全部通过，并新增共享图标与品牌锁定回归测试。

## 8. 长期图标设计原则

- 正式界面一律使用统一网格、笔画、光学重量、视觉重心和状态规范的成品图标系统。
- CSS 边框、圆点、伪元素拼图和线框占位符只能用于早期结构验证，不得进入高保真原型或最终产品界面。
- 仓库已有合适的本地 SVG 或成熟图标库时直接复用；只有位图插画、纹理或场景图确有价值时才使用图像生成模型，导航图标不转为位图资产。
