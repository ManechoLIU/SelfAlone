# 老己 PPT 工作台与书籍作品生命周期设计

- 状态：已归档；当前有效规则已并入原型 PRD 与 UI 设计规范
- 日期：2026-08-12
- 范围：PPT 会话归属、移动/桌面工作台、书籍“读书 PPT”列表、生成任务与完成作品
- 参考：`open-design-ui-reference/laoji-ppt-workbench-flow-review.html`、`IMG_4012.PNG` 至 `IMG_4021.PNG`

> 本文仅保留专项设计过程和决策背景，不是开发事实源。实现以 `docs/prd/laoji-mvp-prototype-prd.md` 与 `docs/ui/laoji-mvp-ui-design-spec.md` 为准。

## 1. 已确认目标

老己把对话作为创作过程的上下文，把书籍详情作为任务与完成作品的找回位置。桌面端在当前会话右侧展开作品工作台；手机端从会话或书籍列表进入全屏作品层。PPT 预览和生成过程都使用纵向瀑布流，不依赖“上一页 / 下一页”。

本轮不引入版本管理，不把大纲编辑、模板选择或未启动生成的草稿显示在书籍 PPT 列表中。

## 2. 入口与会话归属

- 从书籍详情首次点击“制作 PPT”：创建绑定当前书籍的新会话，并在该会话中完成范围、要求、大纲和模板选择。
- 在普通对话中提出 PPT 意图：保留当前对话；书籍不明确时在当前对话选择一本，选择后继续当前会话，不再新建会话。
- 从会话中的任务或作品卡进入：退出作品层时返回原会话、原消息位置和输入草稿。
- 从书籍“读书 PPT”列表进入：退出作品层时返回该书的“读书 PPT”区域。
- PPT 列表和作品页不固定显示“返回会话”。返回目的地由进入路径决定；来源会话仅作为内部追溯关系保留。

## 3. 三个独立实体

### 3.1 PPT 草稿

草稿包含范围、要求、大纲、模板选择和保存状态，只存在于创作会话中。生成大纲、编辑大纲、选择模板都属于准备阶段，不属于“PPT 生成中”。

草稿不会出现在书籍“读书 PPT”列表。删除尚未启动生成的创作会话时，可以一并删除该草稿；实现必须在删除确认中明确结果。

### 3.2 PPT 生成任务

只有用户确认模板并点击“开始生成 PPT”后才创建生成任务，状态进入 `generating`。任务记录总页数、当前正在生成的页、已经完成的页、失败位置、来源草稿、来源会话和书籍。

生成任务出现在书籍“读书 PPT”列表顶部，也出现在来源会话的任务卡中。两处读取同一个任务状态源。

### 3.3 PPT 完成作品

所有页面和可下载 PPTX 均保存成功后，生成任务转换为独立完成作品。完成作品保留生成时间、模板、页数、来源书籍和可选来源会话关系。

从旧作品编辑大纲或重新生成时，系统以旧作品内容创建新的草稿；只有再次点击“开始生成 PPT”才创建新的生成任务。新任务成功后形成另一份独立作品，不覆盖旧作品，也不显示“版本 1 / 版本 2”。

## 4. 严格状态机

```text
会话草稿
  范围与要求
    -> 大纲生成中 / 大纲失败
    -> 大纲编辑与确认
    -> 模板选择
    -> 点击“开始生成 PPT”

生成任务
  queued
    -> generating(page 1 / total ... page n / total)
    -> finalizing
    -> completed（创建独立作品）
    -> failed（保留已完成页，可继续生成或删除任务）
    -> cancelled（从列表移除，不影响旧完成作品）
```

“生成中”只指最终 PPT 页面已经开始逐页渲染。大纲生成必须使用“大纲生成中”，不能简称“PPT 生成中”。

## 5. 书籍“读书 PPT”列表

列表只显示：

1. 生成中的 PPT 任务；
2. 生成失败且可恢复的 PPT 任务；
3. 已完成 PPT 作品。

不显示范围草稿、大纲草稿、模板待选择状态或“待生成”条目。

### 5.1 生成中卡片

- 置于完成作品之前。
- 封面使用稳定的生成占位，不伪装成最终模板封面。
- 标题下显示“正在生成第 8 / 12 页”。
- 次级说明为“可以离开，后台将继续生成”。
- 整卡点击进入实时生成页面，不显示下载、删除或“返回会话”。

### 5.2 失败卡片

- 显示“生成失败 · 已完成 8 / 12 页”。
- 整卡进入失败位置和已完成页面。
- 主操作为“继续生成”，低频操作为“删除任务”。
- 失败不删除旧完成作品，也不要求重做范围、大纲或模板。

### 5.3 完成作品卡片

- 显示真实 PPT 封面、标题、生成时间和页数。
- 整卡进入瀑布流预览。
- 作品页提供编辑大纲、更换模板、重新生成、导出和删除。
- “编辑大纲 / 更换模板 / 重新生成”创建新的草稿或生成任务，最终产出独立作品，不覆盖原作品。

## 6. 实时生成页面

手机使用全屏作品层，桌面使用当前会话右侧工作台。两端共用相同状态与内容顺序：

- 顶部显示“正在生成第 8 / 12 页”，不承诺剩余时间。
- 瀑布流中已完成页显示真实渲染结果。
- 当前页显示骨架和“第 8 页生成中”。
- 后续页显示页码、页标题和“等待生成”。
- 每页完成后原地替换骨架，不把用户滚动位置强制拉回顶部或底部。
- 用户离开页面不终止后台任务；再次进入恢复页进度和滚动位置。
- 所有页面生成完后进入“正在完成文件”；预览和 PPTX 都持久化成功后才标记完成。
- “停止生成”只放在更多菜单，并要求确认；停止后不保留为失败任务。

## 7. 大纲与模板的跨端设计

- 大纲是一份有页边界和文本层级的连续文档，不是标签加输入框的表单堆砌。
- 标题、副标题、内容要点和配图意图通过字号、字重、缩进、项目符号和留白表达。
- 手机点击正文直接编辑，仅当前段落显示轻量操作；键盘弹起后主操作不遮挡焦点内容。
- 模板选择展示真实 16:9 封面；手机双列浏览，桌面在右侧工作台比较。
- 选择模板本身不创建生成任务；用户点击唯一主操作“开始生成 PPT”后才进入生成状态。

## 8. 恢复、错误与删除

- 会话卡、书籍任务卡和生成页面必须读取同一个生成任务状态，不能分别模拟进度。
- 网络中断时保留已完成页并标记任务失败；重试从失败位置继续。
- 作品生成失败或取消时不覆盖、隐藏或删除此前完成的任何作品。
- 删除完成作品只删除被选中的作品；删除生成任务只删除该任务及未完成结果。
- 初次加载、真实空列表、请求失败和正常列表使用不同状态；加载或失败不得闪现“还没有 PPT”。

## 9. 开发验收

1. 编辑大纲或选择模板时，书籍列表不出现“生成中”。
2. 点击“开始生成 PPT”后，会话卡和书籍卡同时显示同一页进度。
3. 点击生成中卡片能看到已完成、当前生成和等待生成的页面。
4. 从会话与书籍列表进入同一任务时，返回分别回到各自入口。
5. 失败任务保留已完成页并可继续；旧作品始终可打开。
6. 重新生成成功后列表新增独立作品，不覆盖旧作品，也不出现版本号。
7. 桌面保留会话与右侧工作台；手机使用全屏作品层和安全区适配。

## 10. 明确不做

- 不提供“创建新版本”、版本切换或大纲历史标签。
- 不在书籍 PPT 列表展示生成前草稿。
- 不提供固定“返回会话”按钮。
- 不以预计剩余时间替代明确页进度。
- 不把桌面侧栏、表单卡片或多栏编辑器压缩成手机页面。
