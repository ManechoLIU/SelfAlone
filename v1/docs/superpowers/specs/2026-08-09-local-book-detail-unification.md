# 本地书详情页统一设计

## 目标

本地导入的 EPUB 与 PDF 对用户呈现为同一种“本地书”，不以文件格式拆分页面信息架构、视觉层级或操作方式。格式差异仅存在于阅读内容的内部渲染。

## 统一结构

- 顶部均显示返回书架、书名、AI 状态和制作 PPT。
- 书籍信息区均显示封面、书名、作者、阅读进度和当前位置，不显示“本地导入”“EPUB”“PDF”等来源或格式文案。
- 均使用“阅读 / 老己笔记 / 读书 PPT”三段导航，并使用相同的按钮结构和切换行为。
- 老己笔记均直接平铺；不显示引用型、独立型、划线/笔记筛选或“回到原文”操作。
- 笔记卡片在鼠标悬浮、键盘聚焦或触摸激活时显示“删除 / 编辑 / 复制”。
- 阅读界面不常驻笔记编辑器，也不为未打开的右栏预留宽度。用户点击一条划线后，才显示该划线原文及其关联的全部“我的想法”；同一划线允许关联多条想法。
- 读书 PPT 均使用同一种作品卡片；有数据时不显示空状态提示。

## 允许的阅读区差异

- EPUB 阅读区按章节排版连续文本。
- PDF 阅读区按页展示内容并保留缩放、页码和目录。
- 扫描版 PDF 无法选中文字时可以显示能力降级提示；这是内容状态，而不是另一套页面样式。
- 上述差异只属于内容渲染器内部能力，不得据此分别设计书籍详情、划线、笔记、PPT 或响应式界面，也不再将“是否同步统一 EPUB/PDF”作为待确认问题。

## 响应式与可访问性

- 桌面端默认显示目录和正文；点击划线后将上下文侧栏展开为第三列。
- 中等宽度使用右侧抽屉显示划线上下文；手机端使用底部抽屉，不压缩正文。
- 导航和悬浮操作必须支持键盘焦点；操作按钮不少于 44px 触控高度。

## 验收

- 两个页面都不出现面向用户的 EPUB、PDF、本地导入来源字样。
- 两个页面拥有同序的三段导航、同构笔记卡片和同构 PPT 卡片。
- 两个页面都能通过鼠标、触摸、Enter 或空格激活划线，并在上下文侧栏显示该划线的全部想法；关闭按钮、背景点击和 Escape 均可收起。
- 删除最后一条笔记后显示空状态；编辑回填当前笔记；复制读取当前笔记正文。
- EPUB 阅读进度继续保存；PDF 也显示并保存阅读进度。
