# PPT 预览状态布局设计

## 1. 范围与目标

本设计只调整 `PPT-03` 模板选择、逐页生成和完成作品三个状态的工作区布局，不改变大纲、模板、生成任务或完成作品的数据模型。

目标：模板选择时方便比较；开始生成后让纵向瀑布流成为唯一视觉主角；完成作品仍能从当前大纲更换模板，同时不覆盖旧作品。

## 2. 已确认方案

采用“状态化收起左栏”。

### 2.1 模板选择态

- 保留左侧模板选择栏，展示真实 16:9 模板封面、模板名和简短适用场景。
- 右侧显示当前模板套用后的完整纵向预览。
- 顶部只保留次操作“编辑大纲”和唯一主操作“开始生成 PPT”。
- 选择模板只更新当前生成前草稿，不创建生成任务。

### 2.2 生成中与正在完成文件

- 用户点击“开始生成 PPT”后，左侧模板与制作流程栏退出布局。
- 作品区扩展为单列全宽瀑布流，宽度仍受舒适阅读上限约束，不拉伸幻灯片比例。
- 顶部显示当前模板名和明确进度，例如“简洁商务 · 正在生成第 3 / 5 页”。
- 所有页面完成后显示“正在完成文件”，不得继续停留在“第 5 / 5 页生成中”。
- 生成中不提供直接切换模板；用户可离开，任务状态和已完成页继续由同一记录保存。

### 2.3 完成作品

- 完成态继续使用无左栏的全宽瀑布流。
- 顶部或作品操作区显示当前模板名和“已完成”，不再把“预览与生成”标为当前步骤。
- 主操作为“下载 PPTX”。
- 次操作为“编辑大纲”“更换模板”“重新生成”。
- “更换模板”以当前作品的大纲快照创建新的生成前草稿，清除旧作品记录参数并回到模板选择态；旧完成作品保持不变。
- “重新生成”同样创建独立生成前草稿，只有再次点击“开始生成 PPT”后才创建新任务。

## 3. 桌面与移动端

### 3.1 桌面

- 模板选择态使用模板栏加预览区。
- 生成中、失败和完成态移除模板/流程侧栏，瀑布流居中并使用更大的可用宽度。
- 失败态在瀑布流上方显示保留页数和失败位置，主操作为“继续生成”。

### 3.2 手机

- 模板选择保持双列真实封面浏览。
- 生成中、失败和完成态本来就是单列作品层，不新增侧栏、抽屉或步骤卡。
- 底部安全区操作保持一个实心主操作；完成态下载为主操作，其余操作为次级。
- 返回仍按进入路径回到原会话或书籍“读书 PPT”，并恢复滚动位置。

## 4. 状态与数据边界

- `ready`：模板选择草稿，可更换模板，不进入书籍作品列表。
- `generating`：最终任务已创建，显示第 N / 总页数。
- `finalizing`：页面已完成，正在持久化预览与 PPTX。
- `error`：保留模板、大纲和已完成页，可从失败页继续。
- `complete`：独立完成作品，可下载或派生新草稿。

任何派生操作都不得修改旧任务或旧作品记录。

## 5. 实现边界

- 调整 `prototype/laoji-ppt-preview.html` 的生成、失败和完成态结构。
- 调整该页面内的定向样式，避免修改全局设计令牌。
- 在 `prototype/assets/laoji.js` 中同步 `generating`、`finalizing`、`error`、`complete` 的布局状态和文案。
- 更新相关静态契约与生命周期测试。
- 不修改 `prototype/laoji-ppt-materials.html`、书籍详情、设置或阅读器。

## 6. 验收标准

1. 模板选择态保留模板比较栏；开始生成后该栏不再占据布局宽度。
2. 生成、失败和完成态的瀑布流获得完整作品区宽度，页面比例和阅读上限稳定。
3. `finalizing` 明确显示“正在完成文件”。
4. 完成态不再显示进行中的流程步骤。
5. “更换模板”返回模板选择草稿，旧完成作品不被覆盖。
6. 桌面 1024、1200、1440px 无横向溢出或内容截断。
7. 手机 360、390、430px 中作品层单列、操作区不遮挡内容、触控目标不小于 44px。
8. 键盘可到达编辑大纲、更换模板、重新生成和下载操作；状态不只依赖颜色表达。
9. PPT 生命周期、移动会话、链接与全量原型回归测试通过。
