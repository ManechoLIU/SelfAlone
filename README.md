# SelfAlone

老己是一个以对话为入口的个人书库与任务工具。当前开发版本为 `redesign-v2`。

## 文档导航

- [`TASK_LEDGER.md`](TASK_LEDGER.md)：唯一当前任务台账，记录当前目标、工作包、状态、阻塞、下一步、验收和证据。
- [`MEMORY.md`](MEMORY.md)：项目级长期记忆，只保存稳定、可复用且有证据指针的结论。
- [`WIKI_INDEX.md`](WIKI_INDEX.md)：知识入口，说明结构化事实、原始资料和查询顺序。
- [`SKILL.md`](SKILL.md)：老己项目的写作、执行、判断、验收与落档风格。
- [`redesign-v2/SPEC.md`](redesign-v2/SPEC.md)：产品目标、对象、功能、流程、状态和验收。
- [`redesign-v2/DESIGN.md`](redesign-v2/DESIGN.md)：共享视觉规范与唯一视觉文档入口。
- [`redesign-v2/DESIGN-WEB.md`](redesign-v2/DESIGN-WEB.md)：桌面 Web 专属布局、交互与视觉验收。
- [`redesign-v2/DESIGN-MINIAPP.md`](redesign-v2/DESIGN-MINIAPP.md)：微信小程序专属布局、交互与视觉验收。
- [`redesign-v2/TECHNICAL.md`](redesign-v2/TECHNICAL.md)：MVP 架构、数据、接口、任务、安全与发布边界。
- [`redesign-v2/design-reference/README.md`](redesign-v2/design-reference/README.md)：全项目统一使用的完整视觉定稿、流程 / 结构参考与排除说明。
- [`AGENTS.md`](AGENTS.md)：协作边界、修改规则、安全和交付要求。
- [`EVOLUTION.md`](EVOLUTION.md)：可复用经验和错误预防，不是需求事实源。

## 当前边界

- 产品、视觉与技术以 `redesign-v2/` 的对应事实源为准；已删除旧版只保留在 Git 历史中，不默认恢复或继承。
- 当前工作与验收状态只以 [`TASK_LEDGER.md`](TASK_LEDGER.md) 为准，不把参考图、计划或历史版本称为当前实现。
- 国内版 MVP 固定支持 DeepSeek、Kimi、GLM、通义千问四家用户自有文本模型，并使用腾讯官方微信读书 API Key 接入。

同一规则只保留一个事实源；其他文档只链接，不复制。
