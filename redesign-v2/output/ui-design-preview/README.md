## 使用规则

- 未列入“已确认”的图片默认为探索稿，不作为实现依据。
- 参考稿与事实源冲突时，以 `DESIGN.md` 和 `SPEC.md` 为准。
- 生成图中的错字、伪图标和非预期细节不得被实现继承。
