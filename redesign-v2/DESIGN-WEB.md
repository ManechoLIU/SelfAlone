# 老己桌面 Web 视觉规范

- 状态：v2 桌面 Web 当前视觉事实源
- 上位共享规则：[`DESIGN.md`](DESIGN.md)
- 产品行为：[`SPEC.md`](SPEC.md)

## 1. 范围与原则

本文只定义桌面 Web 的应用外壳、布局、组件形态、鼠标与键盘交互、页面参考和视觉验收。桌面 Web 目标视口为 `768 / 1024 / 1200 / 1440px`；具体技术断点在技术设计阶段确定，不使用平台名称代替断点。

### 1.1 参考画布与真实浏览器验收

- 桌面 Web 是响应式界面，不把运行时窗口固定为单一尺寸。已确认参考原图必须保留原始尺寸与哈希；`1440×1024px` 只作为纵横比相容时的稳定开发对照副本与完整页面构图基准，不得冒充用户真实浏览器视口，也不得为了统一尺寸拉伸、裁掉有效内容或改变布局。
- 真实浏览器主验收使用用户当前桌面环境的 `100%` 浏览器缩放，分别记录外窗尺寸、CSS 视口、浏览器缩放、设备像素比和截图来源。2026-08-24 已在用户 Chrome 现场验证：外窗 `1440×900px`、CSS 视口 `1440×844px`、缩放 `100%`、设备像素比 `2`；该真实环境是桌面 Web 当前主视觉验收基准，`DPR 1` 仅可作为自动化补充环境。
- 操作系统截图通常按设备像素输出，浏览器控制或开发者工具截图可能按 CSS 像素输出；文件像素必须结合 `capture_source` 判断，不得用“截图像素必须等于 CSS 视口”或“DPR 必须为 1”单独宣告通过或失败。
- 图片模型、Figma 或外部工具返回的页面图先保留在所属 `output/` 或原稿位置。只有用途、状态、预期画布和转换方式已登记，且无拉伸、无有效内容裁切时，才可建立开发对照副本；机器门禁按索引中的角色与预期尺寸校验，不得按文件名猜测或强制所有桌面图片同尺寸。
- `768 / 1024 / 1200px` 继续用于响应式实现验收；同状态视觉对照先在用户真实 `1440×844px` CSS 视口完成，再检查这些宽度下的自适应结果和 `1440×1024px` 完整页面构图。

- 桌面适合并行查看会话上下文与当前任务，但最多只并列一个直接相关的任务工作区。
- 主要依靠连续表面、留白、对齐和分隔线组织内容，不堆叠卡片。
- 鼠标悬停只提供辅助发现，关键操作必须可键盘访问且不依赖悬停。

## 2. 桌面应用外壳

### 2.1 导航与背景

- 应用内左侧主导航使用 `nav-surface #E7EAE8` 雾青灰纸面，右侧主画布使用 `desktop-canvas #F1F1EF` 暖象牙纸白；不得改成明显浅绿、冷白或用半透明绿色遮罩二次染色。输入面可继续使用更亮的 `surface`。
- 导航必须使用 [`assets/backgrounds/desktop-left-rail-vintage-transparent-v2.png`](assets/backgrounds/desktop-left-rail-vintage-transparent-v2.png) 作为低对比、低饱和的透明远山、树木与亭子叠加层；素材本身不得烧录纸白或棋盘格背景。宽导航中素材贴底居中、按约导航宽度 `120%` 展开，整体保持约 `.44` 的低存在感，并用自上而下的 Alpha 渐变消除矩形边界；场景在约 `1024px` 高画布中由远山自然进入下半部，树亭落在底部，不保留使主体缩成一团的大块内部空白。窄导航可进一步降低存在感，但不得放大成独立插画。
- 水墨不得上移覆盖导航项、进入内容列或形成抢占注意力的半栏主插画。
- 左上角直接使用正式老己头像；宽导航显示头像与“老己”字标，窄导航只保留头像。
- 当前导航项通过浅背景或轮廓、深绿图标和文字共同表达，不依赖单一颜色。

### 2.2 导航宽度与工作区

- 导航轨可通过边缘拖动在图标窄态和图标加文字宽态之间吸附；默认不设置常驻收起按钮。
- 分隔线悬停时扩大热区并显示拖拽反馈；键盘聚焦后可用方向键调整，Enter 切换两档。
- 没有可并行上下文时，主画布不为空面板预留宽度。
- 主画布旁最多显示一个当前上下文工作区，只允许这两个区域之间调整宽度。
- 工作区低于安全宽度时吸附为标明任务类型和当前阶段的窄条；向外拖动或双击恢复上次宽度。
- 视口宽度不足时，上下文工作区收起或进入次级视图，不把桌面多栏纵向堆叠成伪手机布局。

### 2.3 页面标题与密度

- 常驻导航已经明确当前页面时，主画布通常省略同名 H1；统一书架按 03 号绑定基线保留“读书”页标题，不得因通用规则删除。
- 首个内容分组标题与宽导航“老己”字标基线对齐，允许约 `8px` 视觉修正。
- 页面留白 `24–40px`；小控件圆角 `4px`、常规控件 `8px`、浮层 `12px`、独立模态 `16px`。
- 普通按钮高度至少 `40px`；图标按钮命中区不小于 `44×44px`。

## 3. 桌面品牌与桌宠

- 桌面账户入口使用左右约等宽分区：左侧以大圆弧暖白纸面承载低对比山水、品牌与角色，右侧账户内容不超过约 `440px` 并垂直居中。
- 山水、角色和圆弧不得越界进入账户区；账户区默认只显示标题、说明、微信主按钮、分隔、邮箱次入口与协议，不直接展示二维码，也不得为未显示的二维码预留空白。
- 点击“微信登录”后打开居中的独立扫码弹窗；弹窗只承载标题、二维码、简短说明与关闭操作，关闭后回到原账户入口。邮箱登录保持低一层级备选，不增加手机号。
- 对话页桌宠依附输入框上沿并避开输入、附件和发送，可使用坐姿持书造型。
- 设置总览和统一书架使用小尺寸坐姿读书桌宠；运行时必须使用 `assets/mascot/laoji-mascot-seated-reading-transparent-v1.png`，不得重新生成、改画或使用带棋盘格的确认源图。在用户真实 `1440×844px` CSS 视口中建议高度 `96–108px`，不因空白放大。
- 设置和统一书架的对话快捷入口位于桌宠肩部右侧；统一书架使用可见圆面约 `38px` 的墨绿色气泡，同时保留不小于 `44×44px` 的透明命中区，视觉间距约 `6–8px`。气泡内部必须使用成熟的白色线性“圆角对话框 + 三个省略点”图标，不使用方框消息、横线文本、字符或 CSS 临时形状替代。统一书架固定在主画布右下安全区，不遮挡封面、来源、滚动条或右下水墨落款。书架构图继续服从 03 号基线，桌宠造型服从 34 号参考，位置关系服从 `library-companion-placement-approved-original.png` 的局部确认范围。
- 关闭控件悬停或键盘聚焦时出现；关闭后桌宠和气泡一同收回左上头像，头像可召回。

## 4. 桌面通用组件

### 4.1 表单、列表与设置

- 输入框和选择器使用白底、`8px` 圆角和 `1px` 边框；聚焦态使用 `2px` 强调色轮廓。
- 设置总览使用分组标题、整行入口和分隔线。文本模型、图片模型和微信读书连接整行可点击，状态位于中间列，行尾只保留一个细箭头。
- 账户区只显示一次“账户与登录方式”入口和一次“退出登录”；绑定、解绑、移除配置、断开连接或同步不在总览并列。
- 会话列表使用统一会话图标、标题与摘要，不用书籍封面代表会话。

### 4.2 免费体验与模型配置引导

- 符合领取条件的新账户只在登录后的对话首页主内容流显示一条轻量卡片条，不放入导航、会话列表、设置总览或独立模态，也不做覆盖页面的首次引导。
- 卡片条只显示小型线性礼物图标、“免费体验额度”和其后的实心“领取”按钮；使用共享 `benefit-soft` 暖纸底、`benefit-accent` 图标与细色边、约 `12px` 圆角和极轻投影，“领取”仍使用品牌墨绿。整体保持单行、紧凑且不扩展成营销卡片，不得增加说明、金额、余额、进度、积分、倒计时或插画。
- 点击“领取”后原位短暂显示“已领取”，随后整条提示移除且不保留空位；领取后不在任务标题、输入区或其他页面常驻显示额度状态。
- 体验不可用或已完成后，用户触发新的 AI 操作且未配置文本模型时，在输入框上方或当前 PPT 阶段操作区就近显示紧凑引导“配置自己的 AI 模型后继续”，唯一主操作为“配置 AI 模型”；不得在页面打开时主动弹窗。进入配置页再返回时恢复原输入、滚动位置和任务阶段。
- “配置 AI 模型”直接打开文本模型配置详情；供应商使用固定下拉列表，`API Key` 使用带显隐操作的密文输入，千问按需显示业务空间 ID，“检测并保存”是唯一主操作。验证中按钮原位加载，失败在字段下说明并保留输入，成功后返回原位置并显示“已配置，可继续”，但不自动发送原消息或启动原任务。
- 领取、重试或配置跳转失败均在原提示或原引导位置反馈，保留当前内容；“配置 AI 模型”可以作为额度耗尽状态的主路径，但不与正常“领取”同时出现。

### 4.3 书架、书籍详情与阅读

- 统一书架在视口宽度 ≥ `1440px` 时使用 5 列；封面宽度按可用高度在约 `160–180px` 间调整，列间距约 `36px`。低于该宽度按可用空间递减列数，保持文字与操作不挤压。
- 用户真实 `1440×844px` CSS 视口下保留“读书”页标题，搜索框与“导入书籍”同处下一行；左栏约 `184px`，搜索与按钮高度 `50–52px`，按钮约 `152px` 宽，五列封面约 `160×224px`，首屏完整显示两排连续书架及来源。较窄视口可把搜索和导入控件收紧到约 `48px` 高，但不得压缩其下方服务行与书架的层级间距。`1440×1024px` 完整页面构图可将封面放宽至约 `180px`，但不得把该尺寸机械搬到较矮真实视口；两种高度都不得改成四列、大封面陈列、最近阅读大卡片或来源分区。
- 阅读进度固定在封面底部状态带，状态文字使用共享 Meta `12/18`，来源位于封面下方并使用成熟图标与短文字；页面右下延续低对比远山，可复用已批准左栏透明素材的中段远山裁切，但只能显示远山，不得出现亭子、大树、旋转、矩形边界或命中遮挡。左栏底部仍完整显示山、树与亭子，不得居中裁掉亭子。
- 未连接微信读书时，在书架搜索框下、书籍网格前放置低强调服务行“连接微信读书”；连接成功后服务行消失。
- 所有本地导入书籍统一显示同一套 `5:7` 动态默认封面模板，不展示原文件封面；底图从 `assets/book-covers/` 三张用户确认素材中按稳定书籍 ID 哈希固定选择，封面内排印真实书名和作者，作者缺失时显示“作者未知”。封面外缘不加描边，只保留一层轻阴影，不叠加书脊色带、径向高光、多层渐变、椭圆伪元素、半透明底层或实色偏移。底图与文字必须保持可读对比，刷新或排序不得换图；封面下仍只保留一行书名。微信读书书籍使用同步得到的真实封面；来源默认使用无底色单色小图标，同名不同来源同时出现时改用“微信”或“本地”短文字。
- 书籍详情顶部使用与书架一致的封面和紧凑信息条：本地书籍继续使用动态默认封面，微信读书使用同步封面；书名、作者、来源形成两层，简介一至两行能完整显示时不出现展开入口。
- 信息条右侧保留轻量描边的“基于本书制作 PPT”，不在阅读标签重复全书进度。
- 本地阅读默认不常驻目录；目录使用不挤压正文的侧抽屉或定位浮层。
- 专注模式隐藏全局导航、详情页头、桌宠和非阅读操作，正文置于舒适行宽中央；顶部持续保留目录、阅读设置和退出，`Esc` 可退出。
- 正文选中后显示“划线 / 写想法 / 和老己聊聊”，工具面不得遮挡选中文字。
- 微信读书详情只采用 `design-reference/07-weread-book-detail.png` 中的信息条、PPT 入口、标签与工具区层级，不继承完整正文、目录或专注阅读。
- PPT 作品使用最多两列的 `16:9` 连续网格；生成中和已完成项保持相同比例，下载为行尾独立图标操作。

## 5. 桌面 PPT 工作区

### 5.1 阶段与范围

- 顶部使用“范围与需求 / 大纲 / 模板 / 生成”四阶段水平步骤条。
- 已完成阶段使用对勾与连线，当前阶段使用实心强调圆点和强调文字，未开始阶段使用中性描边。
- 范围摘要只在存在个性化范围时显示；固定字段按轻量分组纵向排列。
- 工作区底部保持稳定操作区：返回是次操作，推进当前阶段是唯一主操作。

### 5.2 大纲编辑

- 大纲使用类似飞书文档的连续分层文本编辑；页面、要点和说明由段落层级判定，一级页面段落自动计为一页。
- 不显示页卡、页操作按钮或独立页面列表；换行继承当前层级，缩进进入子层级，退格在段首回退层级，删除空段落即删除对应结构。
- 子段落失去所属页面层级时，在原段落位置提示“需要页面层级才能确认大纲”，并阻止确认；恢复层级后才可继续。
- 保存失败和重试在原位置反馈，不打断编辑视线或丢失焦点。

### 5.3 模板选择

- 模板使用双列网格；每项包含真实 `16:9` 预览和模板名称，不要求显示可见风格说明。
- 整项是同一选择目标，不拆分图片与名称的点击区域。
- 选中项同时使用强调边框、浅强调底色和对勾；底部操作区保持稳定。

### 5.4 生成瀑布流

- 生成中、失败和完成使用同一个单列大图瀑布流，页面尽量使用工作区可用宽度并保持 `16:9`。
- 顶部持续显示“正在生成第 N / 总页数页”。已完成页面按顺序出现，末尾只保留一个当前页骨架。
- 新页面完成后只在用户停留于末尾时自动跟随；用户向上查看时不得抢夺滚动位置。
- 失败提示嵌入失败页原位置并保留前页；失败页卡片右上角放低频菜单，提供“删除任务”，二次确认后只清理当前失败任务及其临时已完成页面，不影响会话、书籍或历史作品，删除后不可重试；主要操作仍为“重新生成”和“修改大纲”。
- 完成态连续显示全部页面，不增加缩略图列表、轮播、分页器或“显示 PPT”开关。
- “下载 PPTX”保持唯一主操作；其附近显示一行低强调说明“可在 PowerPoint 或 WPS 中继续编辑”，不增加独立说明卡或确认弹窗。

## 6. 桌面动效与验收

- 悬停、焦点和拖拽反馈不得改变布局；减少动态效果时取消路径位移和缩放。
- 至少在 `768 / 1024 / 1200 / 1440px` 检查导航、主画布、任务工作区、浮层和桌宠。
- 检查无横向溢出、标题空带、内容裁切、浮层遮挡和拖拽热区丢失。
- 检查所有仅在悬停出现的操作都能通过键盘聚焦发现和执行。
- 桌面共享外壳以 `design-reference/02-conversation-and-scope.png` 为主基准；PPT 结构参考不得覆盖该外壳、正式头像、绿色层次和远山亭子背景。
