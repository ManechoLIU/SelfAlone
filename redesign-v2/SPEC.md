# 老己产品功能规格

- 状态：v2 当前产品事实源
- 适用端：响应式 Web，覆盖桌面、平板和手机
- 目标读者：产品、设计、开发、测试与后续 Agent

## 1. 文档职责

本文只定义产品目标、功能边界、业务对象、用户流程、状态和验收结果。视觉语言、组件造型、页面布局、断点和动效由 `DESIGN.md` 定义。

`v1/` 仅用于核对历史，不是当前版本依据。若旧文档、旧原型或专项记录与本文冲突，以本文为准。

## 2. 产品定义

老己是以对话为主入口、以个人书架为内容基础的阅读与知识输出工具。MVP 让用户完成一条闭环：

```text
同步或导入书籍
→ 阅读、划线和记录老己笔记
→ 从对话或书籍发起读书 PPT
→ 确认范围、需求、大纲和模板
→ 生成、预览并下载可编辑 PPTX
```

目标用户是需要持续学习、整理知识并形成输出的知识工作者。

### 2.1 MVP 成功结果

- 用户能进入产品并管理自己的对话。
- 用户能在一个书架中查看微信读书同步书和本地 EPUB/PDF。
- 用户能查看或阅读书籍内容，建立只属于自己的老己笔记。
- 用户能从一本书生成结构化读书 PPT，并在生成失败后继续任务。
- 核心流程在桌面和手机浏览器都能完成。

### 2.2 MVP 不包含

- 微信、手机号或邀请码登录；
- 微信读书站内全文阅读和全站书目搜索；
- 多书合并、通用非读书 PPT、复杂素材逐条编排；
- 笔记全文搜索、跨书籍笔记中心、复杂阅读统计；
- 本地书删除、回收站和恢复；
- 多人协作、社区、公开分享、付费和订阅；
- 养生、专注力等其他技能入口。

## 3. 核心对象

| 对象 | 含义 | 关键规则 |
| --- | --- | --- |
| 用户 | 账户、头像、昵称与登录邮箱 | 头像昵称与登录邮箱分开管理 |
| 会话 | 普通对话或绑定一本书的 PPT 会话 | 保存消息、输入草稿、书籍上下文和当前任务阶段 |
| 书籍 | 微信读书同步书或本地 EPUB/PDF | 同名不同来源不自动合并；一次 PPT 只绑定一本书 |
| 来源内容 | 原文、个人同步内容或书友观点 | 来源内容只读；书友观点默认不进入 PPT |
| 老己笔记 | 用户为当前书籍创建的私有内容 | 可编辑、删除；引用原文保持只读；不存在跨书总入口 |
| PPT 草稿 | 范围、需求、大纲和模板选择 | 属于会话，不进入书籍作品列表 |
| PPT 任务 | 用户点击“开始生成 PPT”后的逐页生成过程 | 可后台继续、失败恢复，并与会话及书籍读取同一状态 |
| PPT 作品 | 一次完成的独立生成结果 | 可再次打开和下载；重新生成不覆盖旧作品 |

## 4. 信息架构

### 4.1 一级导航

已登录后的一级入口只有：

- 对话
- 读书
- 设置

PPT 只从对话或书籍上下文进入，不设置独立一级入口。

### 4.2 功能区域

| 区域 | 职责 |
| --- | --- |
| 登录与账户恢复 | 登录、注册、忘记密码和重置密码 |
| 对话 | 新建、切换和管理会话；承接普通问答与 PPT 意图 |
| 读书 | 统一书架、微信读书内容、本地阅读、老己笔记和本书 PPT |
| PPT 创作 | 范围、需求、大纲、模板、逐页生成、作品和下载 |
| 设置 | 个人资料、登录邮箱、AI 服务、微信读书连接与账户操作 |

## 5. 全局产品规则

1. 注册后直接进入产品，不以配置向导阻断用户。
2. AI Key 和微信读书 Skill Key 相互独立；未配置时仍可使用不依赖对应服务的功能。
3. 一个会话、一本书、一个草稿和一个生成任务的状态必须可追溯，刷新或跨页面不得静默丢失。
4. 所有提交操作在处理中禁止重复提交。
5. 异步失败保留用户输入、当前对象、阅读位置、草稿和已完成结果，并提供明确恢复动作。
6. 过期请求或旧任务不得覆盖用户后来创建的新状态。
7. 所有列表和数据工作区区分初次加载、真实空数据、搜索或筛选为空、请求失败和正常内容。
8. 手机按单任务组织；桌面可以并行展示相关上下文，但两端共享同一业务状态。

## 6. 功能规格

### 6.1 登录、注册与找回密码

- 使用邮箱和密码登录或注册；密码长度为 8–64 个字符。
- 注册成功后自动登录并进入对话，不展示配置向导。
- 登录失败保留邮箱；密码错误时清空密码。
- 找回密码的结果不得泄露邮箱是否已注册。
- 提交中禁止重复操作；字段错误和网络错误在当前表单内反馈。

### 6.2 对话

- 登录后默认进入对话。
- 用户可以新建、切换、重命名和删除会话；会话按时间组织。
- 每个会话独立保存消息、未发送输入、绑定书籍和任务阶段。
- 新对话默认没有书籍上下文；可主动选择一本书。
- 用户在普通对话中明确提出制作读书 PPT 时，进入当前会话内的 PPT 流程。
- 书名不明确、同名不同来源或消息包含多本书时，要求用户选择一本，不能自动猜测。
- AI 未配置时允许输入；触发 AI 操作后提示去配置或取消。往返设置后保留输入和书籍上下文。
- 删除会话会删除尚未开始最终生成的 PPT 草稿；已开始生成的任务和完成作品仍保留在对应书籍中。

### 6.3 统一书架

- 微信读书同步书与本地 EPUB/PDF 出现在同一个书架。
- 书架搜索只匹配已有书籍的书名和作者；不发起外部搜索。
- 同名不同来源显示为独立书籍，不自动合并。
- 书籍来源和文件格式保留在数据中，但不作为书架筛选或卡片操作入口。
- 用户可以连接微信读书、立即同步或导入 EPUB/PDF。
- 导入显示上传与解析状态；失败保留文件名和可操作原因。
- MVP 不提供单书删除、移除或回收站。

### 6.4 书籍详情

- 微信读书与本地书共用同一书籍详情概念和返回路径。
- 微信读书书籍提供：我的笔记、书友笔记、老己笔记、读书 PPT；不提供站内全文阅读。
- 本地书提供：阅读、老己笔记、读书 PPT。
- 每本书都可发起“制作 PPT”。
- 本书的 PPT 区只显示生成中任务、可恢复失败任务和完成作品；生成前草稿只从原会话继续。

### 6.5 微信读书内容

- 我的笔记包含用户自己的同步划线和想法，内容只读。
- 书友笔记最多展示 20 条热门划线和 20 条高赞评价，内容只读。
- 同步原文被激活后提供复制和写老己笔记；操作只作用于当前条目。
- 书友观点默认不进入 PPT；只有用户在 PPT 范围中明确选择后才可使用，并保留作者和来源。
- 某类内容获取失败时只影响对应区域，其他已经同步的内容继续可用。

### 6.6 本地 EPUB/PDF 阅读

- EPUB 与 PDF 使用一致的阅读功能概念：目录、显示级别、阅读进度、专注阅读、复制、划线和写笔记。
- EPUB 支持连续正文阅读和精确划线。
- PDF 优先使用文件内置目录；没有可靠目录时尝试从文本结构提取；仍不可靠时降级为页码或缩略页导航，不生成虚假章节。
- PDF 支持跨页选区和划线；缩放、刷新和重新打开后应尽量恢复到相同原文。
- 扫描版、无文本层或文本顺序异常的 PDF 可以阅读时继续允许阅读，但禁用精准划线并说明原因。
- 加密且无法读取或没有可渲染页面的 PDF 阻止继续，并提供返回路径。
- 重新打开书籍时恢复阅读位置；无法准确恢复划线时提示重新定位，不静默标到错误文字。

### 6.7 老己笔记

- 老己笔记只属于当前书籍，没有跨书籍汇总入口。
- 用户可以创建不引用原文的笔记，也可以从原文创建引用笔记。
- 用户笔记可编辑、删除和复制；引用原文、来源、作者和位置保持只读。
- 同一条原文可以关联多条老己笔记。
- 删除只移除当前用户笔记，不删除书籍、原文、同步内容或本地划线。
- 删除或保存失败时保留原内容并允许重试。
- 原文和笔记操作按当前内容出现，不作为每条记录的常驻操作区。

### 6.8 PPT 双入口与会话规则

PPT 有两个入口，进入后复用同一主流程：

```text
普通对话提出 PPT → 选择或继承一本书 → 继续当前会话 ┐
                                                   ├→ 共同主流程
书籍详情“制作 PPT” → 自动带入当前书 → 创建绑定书籍的新会话 ┘
```

- 普通对话入口保留原消息和会话历史；只有书籍不明确时才要求选书。
- 书籍详情入口自动带入书籍，并创建绑定该书的新会话。
- 两个入口进入范围阶段后使用相同草稿结构、阶段规则和作品结果。
- 返回目的地由进入路径决定，并恢复原消息位置、输入草稿和作品滚动位置。

### 6.9 PPT 主流程

#### A. 范围与需求

- 范围按书籍能力提供整本书、指定章节和已有老己笔记。
- 微信读书没有可靠章节信息时不显示章节选择，并引导使用可用笔记。
- 书友观点需要用户明确选择。
- 需求包括用途、分享对象和页数档位；补充要求继续通过当前会话输入。
- 所选范围没有可用内容时阻止生成并提供修改范围的出口。
- AI 未配置时允许先完成范围和需求；点击生成大纲后再引导配置。

#### B. 大纲

- 大纲生成不称为“PPT 生成中”。
- 用户可编辑标题、正文、要点、配图意图、来源和页面顺序，也可添加或删除页面。
- 大纲至少保留一页，并自动保存。
- 保存失败时保留修改；离开前允许重试、继续编辑或放弃未保存内容。
- 重新生成大纲会覆盖当前生成前草稿，需要在已有人工修改时确认；不提供大纲版本历史。
- 未明确确认大纲不得进入模板和最终生成。

#### C. 模板与最终生成

- MVP 模板为简洁商务、知识卡片和图文叙事。
- 用户确认模板并点击“开始生成 PPT”后，才创建生成任务并使用“生成中”状态。
- 进度统一显示“正在生成第 N / 总页数页”，不承诺剩余时间。
- 生成页按纵向连续顺序展示已完成页、当前页和等待页。
- 用户离开后任务继续，并能从原会话和书籍 PPT 区找回。
- 失败保留大纲、模板和已完成页面，可从失败位置继续或删除任务。
- 完成作品可以再次打开、下载 PPTX、编辑大纲、更换模板或重新生成。
- 重新创作先建立新的生成前草稿；再次开始生成后形成独立作品，不覆盖旧作品，也不显示版本号。

### 6.10 设置与账户

- 设置首页聚合个人资料、服务状态和账户安全，不承载所有详细表单。
- 个人资料只管理头像和昵称：点击头像上传；昵称修改后显式保存。
- 登录邮箱在独立安全流程中修改，先验证当前邮箱，再验证新邮箱。
- AI 服务只允许一套当前生效配置；供应商为 DeepSeek、Kimi 或 GLM，不向用户暴露模型选择。
- AI 新 Key 验证成功后才替换旧 Key；撤销后阅读和笔记继续可用。
- 微信读书使用独立 Skill Key。保存不等于连接成功；测试成功后才能同步。
- 清除微信读书凭证会停止后续同步，已同步内容保留只读，用户笔记不删除。
- 修改微信读书 Key 后不自动合并不同账号数据。
- 退出登录、修改密码和删除账户属于账户安全操作；删除账户需要再次验证并说明影响。

## 7. 关键状态与恢复

| 场景 | 必须保留 | 恢复动作 |
| --- | --- | --- |
| AI 未配置或失效 | 当前输入、书籍和任务意图 | 配置后返回原位置；也可取消 |
| 微信读书同步部分失败 | 已成功书籍和内容 | 重试失败部分 |
| 本地书导入失败 | 文件名和失败原因 | 重试或重新选择 |
| 列表加载失败 | 缓存数据或原页面结构 | 就地重试 |
| 笔记保存或删除失败 | 编辑内容或原笔记 | 重试或继续编辑 |
| PPT 范围内容不足 | 已选需求和会话消息 | 修改范围 |
| 大纲生成失败 | 范围和需求 | 重试或返回 |
| 大纲保存失败 | 未保存修改 | 重试、继续编辑或放弃 |
| PPT 最终生成失败 | 大纲、模板和已完成页 | 从失败位置继续或删除任务 |
| 页面刷新或跨端返回 | 会话身份、草稿、任务阶段和进入路径 | 恢复到最近有效状态 |

## 8. 跨端行为

- 桌面优先支持会话与相关工作内容并行查看；手机一次聚焦一个主要任务。
- 手机不依赖悬停；目录、会话列表、笔记和作品使用可进入、可返回的次级视图。
- 大纲在手机和桌面都能查看、编辑、调整页面顺序、查看来源和确认。
- 生成和作品在两端都按纵向连续内容浏览，不依赖上一页或下一页按钮。
- 键盘弹出、系统安全区、长书名、长笔记和 200% 文本缩放不得遮挡当前输入或主要提交动作。
- 所有返回操作根据真实进入路径恢复，不设置脱离上下文的固定返回目标。

## 9. 验收清单

- [ ] 一级导航只有对话、读书和设置。
- [ ] 用户可以在不配置任何 Key 的情况下进入产品并使用不依赖服务的功能。
- [ ] 微信读书书籍不出现站内全文阅读。
- [ ] 同名不同来源书籍不自动合并。
- [ ] 本地 EPUB/PDF 能阅读；不支持精准划线的 PDF 有明确说明。
- [ ] 老己笔记只属于当前书籍，用户内容可编辑删除，引用来源只读。
- [ ] 普通对话和书籍详情两个入口都能进入同一 PPT 主流程。
- [ ] 普通对话继续原会话，书籍详情创建绑定书籍的新会话。
- [ ] PPT 必须经过范围、需求、大纲确认和模板确认。
- [ ] 只有点击“开始生成 PPT”后才创建任务并显示“生成中”。
- [ ] 会话、书籍和作品中的任务状态一致。
- [ ] 失败保留输入、草稿、上下文和已完成结果。
- [ ] 重新生成产生独立作品，不覆盖旧作品。
- [ ] 桌面和手机都能完成核心流程，且手机不是桌面布局的机械压缩。
- [ ] 所有数据表面区分加载、真实空、筛选空、失败和正常内容。
