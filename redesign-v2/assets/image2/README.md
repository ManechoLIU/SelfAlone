# Image 2 图片素材

本目录保存从已删除旧版整理到 v2 的 Image 2 生成素材；来源原件只可从 Git 历史追溯。

这些图片仅用于视觉参考，不是产品或视觉事实源；当前规则仍以 `redesign-v2/SPEC.md` 和 `redesign-v2/DESIGN.md` 为准。

## 分类

- `ui-mockups/`：对话、书架、阅读器和 PPT 的桌面端/移动端组合参考图。
- `flow-overviews/`：核心流程总览及备选总览。
- `workbench-reference/`：PPT 工作台统一外壳和流程评审参考图。
- `book-covers/`：书架与书籍上下文可复用的生成封面。

共 14 张 PNG：4 张 UI 参考图、2 张流程图、2 张工作台参考图和 6 张书籍封面。

旧版 `assets/generated-images/` 未复制到这里，因为其中混有外部产品截图、浏览器错误页和旧原型截屏，不能确认全部属于 Image 2 生成结果；需要追溯时只读取 Git 历史，不恢复为当前素材。
