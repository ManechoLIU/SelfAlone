# 读书模块剩余主界面产出计划

## 目标与非目标

- 目标：在现有统一书架和本地阅读参考图基础上，补齐书籍详情中的「划线与想法」「老己笔记」「PPT 作品」三个通用主界面。
- 非目标：不重做统一书架、本地阅读正文、目录、阅读设置或专注模式；不为本地书籍与微信读书复制两套相同页面；不设计移动端；不实现原型或业务代码。

## 事实源与输入

- 产品行为：`redesign-v2/SPEC.md`
- 视觉规则：`redesign-v2/DESIGN.md`
- 完整视觉基准：`redesign-v2/design-reference/02-conversation-and-scope.png`、`redesign-v2/design-reference/03-reading-library.png`
- 现有本地阅读参考：`redesign-v2/output/ui-design-preview/product-design/book-detail/reader-feedback-comprehensive-candidate-v3.png`
- 现有探索稿只用于识别问题，不自动晋升为开发参考。

## 已确认设计

- 三个标签页共享同一个书籍详情外壳，书籍来源只改变可用内容与元信息，不改变页面结构。
- 「划线与想法」使用单列连续内容流，不显示目录侧栏。
- 不设置固定页码字段。章节或其他定位信息可能识别不到；没有可用定位信息时不显示空标签、占位符或虚构位置。
- 本地书籍只有在存在可靠定位时，定位信息本身才是跳回原文的交互目标；不显示独立的“查看原文”按钮，也不把引用正文整体设为跳转区。
- 微信读书的定位信息只读，不表现为可点击。
- 三张图均沿用青瓷复古书卷外壳、真实老己头像与桌宠、左侧贴底远山树木亭子，以及克制的单主操作层级。
- 图像模型只负责不含角色的界面底稿：头像圆位和桌宠区域必须留空。左上头像使用 `assets/avatar/laoji-avatar-qingci-chibi-v2.png`，坐姿持书桌宠使用已确认设置参考图中的原始像素，二者在生成后通过确定性裁切与合成加入；不得让模型重绘或近似复刻。

## 工作包与所有权

### 工作包 1：同步事实源

- 负责人：主 Agent。
- 允许修改：`redesign-v2/SPEC.md`、`redesign-v2/DESIGN.md`。
- 禁止修改：`v1/`、原型、其他模块文档和既有图片。
- 结果：把可选定位、直接点击定位和无定位状态写回各自事实源，不复制视觉细节到产品文档。

### 工作包 2：生成规格与首轮视觉稿

- 负责人：主 Agent。
- 允许创建：`redesign-v2/work/reading-module-main-views-imagegen-spec.json`。
- 允许创建图片：
  - `redesign-v2/output/ui-design-preview/product-design/book-detail/book-detail-highlights-and-thoughts-v1.png`
  - `redesign-v2/output/ui-design-preview/product-design/book-detail/book-detail-laoji-notes-v1.png`
  - `redesign-v2/output/ui-design-preview/product-design/book-detail/book-detail-ppt-works-v1.png`
- 前置依赖：用户明确授权模型、3 次调用、目标尺寸与上述输出路径。
- 停止条件：首轮三张图产出后立即停止调用；不得自动重试或更换付费模型。

### 工作包 3：独立只读审查

- 负责人：`luna_worker` 子代理，只读，无文件所有权。
- 审查对象：同一仓库根目录、当前提交、当前未提交 diff 和三张首轮图片。
- 核查：页面范围、共享外壳、来源差异、无定位状态、重复操作、文字错误、伪图标、布局冲突与遮挡。
- 禁止事项：不得修改、删除、重命名或晋升任何图片；不得回退其他人的改动。

### 工作包 4：主 Agent 验收与用户定稿

- 负责人：主 Agent。
- 验证：逐张视觉检查；核对像素尺寸、文件格式和文件非空；运行文档残留扫描、链接检查与 `git diff --check`。
- 用户确认前：图片保持探索稿状态，不进入 `design-reference/`。
- 用户明确确认后：只复制获批图片并最小更新 `redesign-v2/design-reference/README.md`；未获批图片继续留在输出目录。

## 预选视觉状态

- 「划线与想法」：同屏展示一条有可靠定位的本地引用和一条无定位信息的引用，证明两种状态都能成立；不混入目录。
- 「老己笔记」：沿用已确认探索稿的全宽行式列表、充足留白、细分隔线和行尾更多菜单；展示普通笔记、引用型笔记和 AI 整理来源的轻量元信息。引用只使用左侧细竖线和缩进，不做圆角卡片；不显示独立标题或标题化首行；新建或编辑入口保持唯一主操作。
- 「PPT 作品」：展示一个生成中作品和若干已生成作品；不出现失败作品或未提交草稿，作品入口支持查看和下载。

## 验收标准

- 三张主界面结构互不重复，各自覆盖一个开发需要的标签页。
- 书籍来源差异停留在内容与元信息层，不形成两套视觉系统。
- 无页码字段；定位为空时不留视觉空洞；存在本地定位时可从定位文本本身理解其可交互性。
- 与现有本地阅读参考共享同一书籍信息条、标签栏、导航外壳和角色资产。
- 最终图片中的头像和坐姿持书桌宠来自已确认原始素材的确定性合成，不得来自 ImageGen 输出；视觉检查需确认角色与源素材一致。
- 不出现独立“查看原文”、目录侧栏、重复主按钮、伪造跳转或超出 `SPEC.md` 的功能。
- 未经用户明确确认，不提交、推送、发布或写入开发参考索引。
